## 1. 시청자 페르소나 — 매 컷마다 머릿속에 두는 한 사람

**"신입 사무직 김주임."** 채팅 AI(질문→답)만 써봤다. 엑셀·PDF를 손으로 복붙·대조하며 하루를 보낸다.
코딩은 모르고, 두렵다. 무엇보다 **"내 반복업무를 AI에게 시켜 자동화한다"는 발상 자체가 없다** — 즉
'내가 뭘 모르는지도 모르는' 상태다. 직무는 영업/인사/회계/마케팅 중 무엇이어도 무방하다.

촬영 내내 자문할 한 줄: **"김주임이 지금 이 화면을 보고 '어, 이것도 돼?' 하고 무릎을 칠까, 아니면 '역시 IT 얘기네' 하고 닫을까?"**
후자라면 그 컷을 다시 찍는다.

## 2. 절대 잊지 말 5대 사상 → 강사 행동지침으로 번역

이 다섯은 슬로건이 아니라 **촬영 중 손과 입으로 실행할 행동**입니다. 매 파트에 최소 한 번씩 등장해야 합니다.

### ① 장벽 허물기 ("이것도 시킬 수 있구나")
- **행동지침 A — 전문용어 즉시 한 줄 풀이.** 새 단어가 입 밖에 나오는 즉시, 같은 호흡에서 쉬운 말로 푼다.
  예: "조인 — 두 표를 공통 열쇠(쿠폰코드)로 짝지어 붙이는 거예요"(Part 4), "그룹바이 — 같은 것끼리 묶기"(Part 4).
  **규칙: 풀이 없이 다음 문장으로 넘어가지 않는다.**
- **행동지침 B — '내가 코딩 한 줄 쳤나요?' 되묻기.** 시연 후 최소 한 번, "방금 코드 한 줄 쳤어요? 안 쳤죠.
  한국어로 일을 설명한 것뿐이에요"를 변주해 넣는다(Part 1·Part 2의 교정 멘트가 표준 문구).
- **행동지침 C — 일상 비유 고정.** 6유형은 항상 같은 비유로: 뽑기=받아쓰기, 모으기=빨래 한 바구니(양말 한 짝도 안 빠뜨림),
  줄이기=한 달 영수증을 '총 얼마' 한 줄로, 딱지=빨래 색깔별 분류, 쓰기=빈 종이 채우기, 검사=숙제 검사. 파트마다 비유를 바꾸지 말 것.

### ② 채팅 너머의 Agent
- **행동지침 D — "복붙이 아니라 폴더째."** 모든 시연의 1단계는 **폴더를 통째로 여는 장면**이어야 한다.
  채팅창에 내용을 긁어 붙이는 장면은 오직 '대조용 나쁜 예'로만 등장시킨다(Part 1·Part 2의 화면 분할).
- **행동지침 E — "결과가 채팅 답이 아니라 파일."** 시연의 성공 증거는 말풍선이 아니라 **폴더 안 파일이 바뀌는/생기는 것**.
  카메라가 결과 파일(시트가 채워진 `.xlsx`)을 반드시 비추게 한다. "새 파일 만들지 말고 이 파일 채워"를 프롬프트에 명시.

### ③ 재사용·확장 사고
- **행동지침 F — 매 파트 마지막에 '자산으로 남기기' 한 문장.** "이건 한 번 만들면 다음 달 새 파일만 넣고 다시 돌리면 돼요"를
  Part 1~8 모두에 넣는다. Part 4·7·8은 이를 본편으로 시연(두 번째 실행이 거의 한 줄로 줄어드는 장면이 하이라이트 — Part 8 시연 A).
- **행동지침 G — '동료에게 넘기기' 언급.** 재사용 3갈래(다음 달 또 / 다른 업무로 변형 / 동료에게 통째로 넘기기)는 Part 8에서 본편화하되,
  앞 파트에서도 한 번씩 씨앗을 뿌린다.

### ④ 직무 무관(job-agnostic)
- **행동지침 H — 매 유형마다 직무무관 연결 한 문장.** 각 파트에 **"당신 직무가 영업이든 인사든 마케팅이든 회계든, 이 모양은 똑같습니다"** 류
  문장을 최소 1회. 예시는 도구일 뿐임을 강조: "대상만 바뀌지, 시키는 방법은 똑같아요." (각 파트 대본의 '직무무관 연결' 구간이 표준)
- **행동지침 I — 예시 자료를 직무로 못 박지 말 것.** "이건 경리 업무처럼 보이죠? 전혀요"(Part 6) 같은 전환을 활용해
  특정 부서 일로 오해되는 순간 즉시 풀어준다.

### ⑤ 실무 태도(결정성)
- **행동지침 J — 매 시연 끝에 '검산' 한 번.** 예외 없음. AI가 결과를 내면 **반드시 되물어 검산**시킨다.
  표준 검산 동작: ⓐ 표본 몇 건의 근거 되묻기("왜 이렇게 분류/판정했어?") ⓑ 전수 점검("보기 밖 값/빈칸 있어?", "총합이 원본과 같아?") ⓒ 경계 케이스("단가차 10원은 정상, 11원은 위반 — 옳게 갈렸어?", Part 6).
- **행동지침 K — 네 가지 태도를 멘트로 반복.** (1) 규칙이 정답(내 느낌 아님) (2) 애매하면 지어내지 말고 보류(기타/중립/일반, 빈칸은 빈칸) (3) 멀쩡한 건 건드리지 않기(허위경보의 비용 — Part 6) (4) AI 결과는 검산.
  특히 **"빈칸과 0은 다르다"**(Part 3·4·6)와 **"화났다고 다 위험이 아니다"**(Part 1·2·5)는 시리즈의 시그니처 멘트이니 토씨까지 일관되게.

## 3. 톤·언어 가이드 (전 파트 공통)

- **전부 한국어, 쉬운 말, 동사 우선 문장형.** 시청자에게 "~하시면 됩니다"로 말 걸기. 영어 약어 노출 최소화.
- **"AI 일꾼"·"시키다"·"맡기다"** 어휘를 고정으로 쓴다(채팅의 "물어보다"와 대비). Part 0이 만든 "AI 일꾼" 명칭을 끝까지 유지.
- **단정적 수치 금지 영역 주의.** 설문 통계(루트의 `AI 이용현황 설문조사_결과보고_0617.xlsx`)는 "가장 많더라" 톤으로만 인용,
  구체 퍼센트를 단정하지 말 것(Part 1). 반대로 **데모에서 실제로 나온 숫자는 화면 그대로 읽어준다**(예: 9천 줄→44줄, Part 4).
- **데모 수치는 "데모 데이터 기준"임을 한 번 고지.** Part 4의 64.7점·64.1% 같은 값은 예시 데이터에서 나온 것 — 강사는 실제 출력값을 읽어주면 된다.

## 4. 촬영·편집 팁

### 화면 구성
- **2분할 고정 레이아웃 권장:** 왼쪽 = 파일 탐색기(폴더 트리가 보이게) + AI 코딩 도구, 오른쪽 = 결과 파일(엑셀/PDF).
  "지시 → 폴더 → 결과 파일"이 한 화면에서 따라가지게 한다. 결과가 파일로 떨어지는 순간을 놓치지 말 것(행동지침 E).
- **폴더 트리를 항상 노출.** "폴더째 맡긴다"가 이 시리즈의 핵심 비주얼이다. 채팅 단독 화면은 대조용 외엔 쓰지 않는다.
- **6유형 한 장 슬라이드는 Part 1에서 마스터 버전을 확정**하고 모든 파트에서 같은 그림을 재등장(해당 유형 하이라이트만 바꿔). 새로 그리지 말 것.

### 속도·길이
- **긴 AI 출력은 배속/컷.** AI가 520건·9천 줄을 처리하며 길게 토해내는 구간은 1.5~2배속 또는 점프컷. "처리 중" 자체는 정보가 아니다.
  단, **결과 파일이 채워지는 순간과 검산 보고 숫자**는 정상 속도로 또렷이.
- 파트당 목표 길이를 큐시트 상단 러닝타임으로 고정. 초과 시 컷 우선순위: ① 긴 AI 출력 → ② 반복 설명 → ③ 잡담성 도입.

### 자막·강조
- **프롬프트 전문은 큰 글씨 자막으로.** 강사가 칠 프롬프트는 미리 메모장에 적어두고 붙여넣어 타이핑 실수로 데모가 끊기지 않게(Part 2 녹화 팁).
- **시그니처 문구는 화면 강조(키워드 자막):** "규칙이 정답", "빈칸 ≠ 0", "검산시킨다", "다음 달에 또 돌아간다", "당신 직무가 뭐든 똑같다".
- 설치 사이트 주소(Part 0: code.visualstudio.com / python.org / nodejs.org / 선택한 도구 공식 문서)는 자막으로. 버전 숫자는 강조하지 않는다("공식대로" 멘트와 한 쌍).
- 계정·로그인 화면은 모자이크.

## 6. 흔한 촬영 리스크와 대처 — 실패를 교육 기회로

이 시리즈의 강점은 **"AI도 틀린다, 그래서 검산한다"**가 교육 내용 자체라는 점입니다. 그러므로 시연 사고는 대부분 **그대로 살려서 교정 장면으로 전환**하는 게 정답입니다.

| 리스크 | 현장 증상 | 대처(되도록 살린다) |
|---|---|---|
| **AI가 엉뚱한 답을 냄** | 규칙 무시, 빈칸을 0으로 채움, 화난 글을 다 '위험'으로 | **컷하지 말 것.** "보세요, 이게 검산이 필요한 이유예요" → 틀린 지점만 짚어 고치게 함(Part 2 4단계, Part 5 검산). 사상 ⑤의 산 증거. |
| **AI가 바로 추측해 진행(되묻지 않음)** | 부실 지시에도 멈춤 없이 결과 생성 | 강사가 멈추고 "② 어떻게·③ 어떤 모양으로가 빠지면 이렇게 멋대로 갑니다"라고 짚는다(Part 2 1단계 주석). |
| **검산 숫자가 안 맞음** | 통합 행수 ≠ 원본(중복 제외), 총합 불일치 | **돌발 대처 멘트 사용:** "한 채널에만 있던 주문을 빠뜨렸네요 → '빠짐없이 넣어'로 다시 시키면 돼요"(Part 3 시연 ① 주석). 틀림→고침이 작업의 일부임을 보여줌. |
| **출력이 너무 길어 지루** | 520건·9천 줄 처리 로그 | 배속/점프컷(§4). 결과·검산만 정상 속도. |
| **버전 UI가 대본과 다름** | 설치 화면·명령이 바뀜 | "공식 사이트가 시키는 대로"로 회피(Part 0). 화면 숫자 따라 하지 말라고 미리 고지. |
| **데모가 완전히 깨짐(재현 불가)** | 파일 깨짐·도구 오류로 진행 불가 | 사전 리허설로 1회 성공 녹화본을 백업 확보. 그래도 깨지면 해당 컷만 백업으로 교체하되, **가능하면 실패→복구 흐름을 살리는 편이 교육적으로 더 강하다.** |

> **리허설 원칙:** 각 파트는 촬영 전 최소 1회 끝까지 돌려 **실제 출력 숫자**(행 수·위반 건수·집계 결과)를 받아 적어둔다.
> 멘트에서 그 숫자를 읽어주면 신뢰도가 올라가고, 검산 장면이 사실과 어긋나지 않는다.

## 7. 각 파트 핵심 시연 1줄 요약 — "무엇을 보여주면 성공인가"

각 파트는 아래 한 컷이 화면에 또렷이 잡히면 **그 파트의 목적을 달성**한 것입니다. 편집 시 이 컷을 반드시 살리세요.

| 파트 | 무엇을 보여주면 성공인가 (핵심 시연 1줄) | 성공의 증거(화면) |
|---|---|---|
| **Part 0** | 폴더만 열고 "이 폴더에 뭐 있어?" → AI가 **실제 파일 6종 목록**을 답한다(파일 한 개도 안 올렸는데) | `1.three_way_match/`의 발주·입고·계산서 등 파일명이 답으로 뜸 |
| **Part 1** | VOC 폴더를 통째로 주고 **520건 3축 분류 → 결과 파일 저장 → 검산**까지 30초 티저. 채팅 대조로 한계 보여줌 | `1_분류표_제출용.xlsx`의 '분류' 시트가 세 칸 채워져 **파일로 저장**됨 |
| **Part 2** | 부실 지시 → **AI가 되묻기** → 업무지시 3요소(①무엇을 ②어떻게 ③어떤모양) 채운 지시 → 검산 → 틀린 곳만 짚어 교정하는 **대화 루프** | "어떤 기준으로? 어디에 적을까요?" 되묻는 화면 + 교정 후 재저장 |
| **Part 3** | 양식 제각각 3파일을 한 표로 **모으기**(같은 뜻 다른 칸 이름 매핑·중복 접기·빈칸 보존) → **원본 행수 대조 검산**. 보너스로 계약서 PDF 줄글 → 표 **뽑기** | `통합주문` 시트가 채워지고 "원본 합계 N줄 = 통합 N줄" 검산 보고 |
| **Part 4** | 9천 줄 GA4 로그를 **쿠폰별 44줄 집계**로 줄이기. 단, **조인이 먼저**. 취소 제외·할인0→ROI 0.0·**가중평균** 검산 | `집계표` 시트 44행 + '적자' 표기 + 검산 4종 숫자(취소 행수·총합 일치·ROI·가중) |
| **Part 5** | 모호해 보이는 분류를 **규칙으로** 520건 일관 처리 → 검산 3건(V091 우선순위 / V035 축독립 / V001 판별불가) + **보기 밖 값 0건** 전수 점검 | '분류' 시트 채움 + "보기에 없는 값/빈칸 0건" 통과 |
| **Part 6** | 세 장부를 **품목코드 키로 대사정리표** → '안내' 규정 그대로 **위반만** 예외목록에 추림 → **경계(10원 정상/11원 위반)** 검산 | `예외목록` 시트에 위반만(멀쩡한 건 안 올림) + 경계 케이스 옳게 갈림 |
| **Part 7** | 제품 정보 시트 → 카피 **before(환각)/after(사실 결속·형식 제약·근거 꼬리표)** → "근거 없는 표현 있어?" **자기 검산**. + 파이프라인 도식 2장 | after 카피에 문장마다 `(근거: …)` 꼬리표 + 검산 "없음" / 조합 도식 |
| **Part 8** | "다음 달 파일 왔다" **재실행 지시가 거의 한 줄**로 줄어듦 + 주문→견적 **변형**(새로 배운 것 없음) + '내 업무 6유형 지도' 워크시트 시범 | 두 번째 실행 한 줄 프롬프트 + GEN-01 견적 모으기 결과 + 채워진 워크시트 |
