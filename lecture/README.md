# 비개발자를 위한 AI 자동화 강의 — 마스터 색인

> 유튜브 강의 영상 교안(촬영 대본/큐시트) 모음의 색인입니다.
> 강사는 각 파트 파일을 그대로 보고 영상을 찍을 수 있습니다.

## 이 강의는 무엇인가

**대상**: 비개발자 — 신입~주니어 사무직. 채팅 AI는 써봤지만, **"내 반복업무를 AI에게 통째로
시켜 자동화한다"**는 발상 자체가 없는 사람.

**형식**: 보는 것만으로 이해되는 유튜브 강의 영상. 일일이 따라 하지 않아도 됩니다. 단, 직접
해보고 싶은 사람을 위해 **Part 0(환경세팅)**을 선택 파트로 따로 제공합니다(정규 90분 본편에는
미포함).

**언어/톤**: 전부 한국어, 쉬운 말. 전문용어는 처음 나올 때 한 줄로 풀어줍니다.

### 이 강의가 깔고 가는 4가지 사상

1. **장벽 허물기** — "이런 것도 시킬 수 있구나"를 깨닫게 해서, 시도조차 못 하던 일에 손대게 만든다.
2. **채팅 너머의 Agent** — 단발 질문/답변이 아니라, 내 파일이 든 폴더를 통째로 주고 작업을 시키고,
   결과 파일을 받고, 틀리면 고치게 하고, '한 번 만들면 매달 다시 돌아가는' 도구로 남긴다.
3. **재사용·확장 사고** — 문제를 AI로 풀고, 그 결과(만든 절차/도구)를 다음 달에 또 돌리고, 다른
   데이터·동료에게 확장한다. 일회성 처리가 아니라 '자산'으로 남긴다.
4. **직무 무관(job-agnostic)** — "당신 직무가 영업이든 인사든 마케팅이든, 반복업무는 결국 아래
   6가지 모양 중 하나"라는 보편 프레임으로 가르친다.

여기에 더해 영상 내내 **실무 태도(결정성)**를 강조합니다 — "규정이 정답이다(내 느낌 말고 규칙으로
판단)", "애매하면 지어내지 말고 보류", "멀쩡한 건 건드리지 않는다(허위경보의 비용)", "AI 결과는
검산시킨다".

## 6유형 택소노미 — 이 강의의 척추

| 코드 | 정식 이름 | 쉬운 이름 | 입력 → 출력 | 한 줄 판별 |
|---|---|---|---|---|
| ① | 추출/파싱 | **뽑기** | 비정형(PDF·이미지) → 표 | "구조 없던 걸 표로 만든다" |
| ② | 취합/통합 | **모으기** | 정형 다수 → 정형 하나 | "행을 보존하며 여러 파일을 합친다" |
| ③ | 집계/분석 | **줄이기** | 정형 → 요약·지표 | "행을 줄여 수치·인사이트로" |
| ④ | 분류 | **딱지 붙이기** | 텍스트 → 범주 라벨 | "이게 뭐냐(정답이 모호)" |
| ⑤ | 초안 작성 | **쓰기** | 자료 → 새 산문 | "없던 글을 쓴다" |
| ⑥ | 검증/검수 | **검사하기** | 데이터+규칙 → 위반 판정 | "규칙에 맞냐(정답이 규칙)" |

**핵심 메시지**: 실제 업무 과제는 보통 이 유형 **1~3개가 조합**된다(예: 뽑기 → 줄이기 → 쓰기).
난이도도 그렇게 올라간다 — 1단계는 단일 유형, 2~3단계는 유형 조합.
