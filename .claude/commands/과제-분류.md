`assignment-factory` 스킬을 **분류(classify) 아키타입으로 고정**해 실행하라.

- 아키타입 라우팅·아키타입 인터뷰 질문은 **건너뛴다** — 분류로 확정.
- `engines/classify/` + `references/classify-engine-guide.md`(items.csv 텍스트 생성 · **우선순위 규칙북** · 규칙 재적용=정답 · **다클래스 macro-F1 + 혼동행렬** 채점)를 사용한다.
- 나머지는 `SKILL.md` 파이프라인 S2~S10을 그대로 따른다(도메인 그라운딩 → 라벨 집합·규칙북 설계 → 단일 입력 items.csv → 텍스트 생성·결함 주입 → 채점기 → eval 4문서 → problem.md → 독립 재계산+적대 리뷰 게이트).
- 핵심 철학: **"모호함을 규칙으로 결정화"** — 분류의 "이게 뭐냐(정답이 모호)"를 자유 판단이 아니라 **우선순위 규칙북**(키워드/패턴 → 라벨, 위에서부터 첫 매치)으로 모든 텍스트가 **유일 라벨**로 떨어지게 만든다. 정답은 시나리오 플래그가 아니라 규칙북을 텍스트에 재적용해 도출(cross_check fail-loud). 함정 = **다중 키워드 충돌**(우선순위 해소) · **경계/약한 신호** · **판별 불가 → 기타/중립**(무리한 추측 금지) · **라벨집합 외 임의값 처벌**.
- 사용자에게는 **테마 · 대상 직무 · 난이도 · 분류 축(들) · 라벨 집합 · 규칙북(우선순위·키워드)**을 인터뷰하라.
- 발행 전 `references/checklist.md` 게이트를 통과해야 한다. 레퍼런스 과제: `problems/marketing/3.voc_classification`.
