`assignment-factory` 스킬을 **집계/분석(aggregate) 아키타입으로 고정**해 실행하라.

- 아키타입 라우팅·아키타입 인터뷰 질문은 **건너뛴다** — 집계/분석으로 확정.
- `engines/aggregate/` + `references/aggregate-engine-guide.md`(spec.csv 시나리오 · raw 로그 전개 · 그룹바이 재집계=정답 · **Computed ±ε 채점**)를 사용한다.
- 나머지는 `SKILL.md` 파이프라인 S2~S10을 그대로 따른다(도메인 그라운딩 → 그룹·지표 정의 → 단일 입력 spec.csv → raw 로그 생성·결함 주입 → 채점기 → eval 4문서 → problem.md → 독립 재계산+적대 리뷰 게이트).
- 핵심: **"정답이 곧 계산"**(정답은 spec 숫자가 아니라 생성된 raw 로그를 재그룹바이해 도출) + 결정성 함정 = **분모 0**(0으로 나누기 규칙) · **반올림 경계**(half-up 규칙·±ε 허용오차) · **가중평균 vs 단순평균**.
- 사용자에게는 **테마 · 대상 직무 · 난이도 · 그룹 단위 · 지표(율/합계/평균)·반올림 규칙**을 인터뷰하라.
- 발행 전 `references/checklist.md` 게이트를 통과해야 한다. 레퍼런스 과제: `problems/marketing/2.email_campaign_metrics`.
