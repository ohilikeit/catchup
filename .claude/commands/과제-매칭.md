`assignment-factory` 스킬을 **매칭(matching) 아키타입으로 고정**해 실행하라.

- 아키타입 라우팅(`references/archetypes.md`)·아키타입 인터뷰 질문은 **건너뛴다** — 매칭으로 확정.
- `engines/matching/` + `references/matching-engine-guide.md`(축 타입 쿡북 §2.5 포함)를 사용한다.
- 나머지는 `SKILL.md` 파이프라인 S2~S10을 그대로 따른다(도메인 그라운딩 → 축↔컬럼 교집합 설계 → 단일 입력 CSV → 생성·결함 주입 → 채점기 → eval 4문서 → problem.md → 독립 재계산+적대 리뷰 게이트).
- 사용자에게는 **테마 · 대상 직무 · 난이도 · 매칭 축**만 인터뷰하라(`references/interview.md`의 Q3/Q4 아키타입 질문은 생략).
- 발행 전 `references/checklist.md` 게이트를 통과해야 한다.
