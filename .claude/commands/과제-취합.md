`assignment-factory` 스킬을 **취합/통합(merge) 아키타입으로 고정**해 실행하라.

- 아키타입 라우팅·아키타입 인터뷰 질문은 **건너뛴다** — 취합/통합으로 확정.
- `engines/merge/` + `references/merge-engine-guide.md`(orders.csv canonical → 양식 다른 다소스 렌더 · dedup·정규화 재구성=정답 · **Set(행)+Exact(정규화 셀) 채점**)를 사용한다.
- 나머지는 `SKILL.md` 파이프라인 S2~S10을 그대로 따른다(도메인 그라운딩 → 표준 스키마·dedup·정규화 규칙 설계 → 단일 입력 canonical csv → 양식 제각각 다소스 생성·결함 주입 → 채점기 → eval 4문서 → problem.md → 독립 재계산+적대 리뷰 게이트).
- 핵심: **"행을 보존하며 합친다"** — 함정 = **중복**(여러 소스 동일 행→1행, 미제거 시 정밀도 처벌) · **양식차**(컬럼명·날짜형식·금액표기 통일) · **표기 불일치**(공백 trim) · **한 소스 전용 행 보존** · **키 충돌 우선순위**. 취합은 자연 단일 산출이라 분리형 N/A.
- 사용자에게는 **테마 · 대상 직무 · 난이도 · 표준 스키마 · 소스 양식 차이 · dedup/정규화 규칙**을 인터뷰하라.
- 발행 전 `references/checklist.md` 게이트를 통과해야 한다. 레퍼런스 과제: `problems/general/2.order_consolidation`.
