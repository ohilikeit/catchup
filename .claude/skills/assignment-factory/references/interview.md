# 인터뷰 (S1) — Q1~Q11

**목적**: 과제 패키지를 찍어내기 전, AskUserQuestion으로 Q1~Q11을 물어 아키타입·엔진·인스턴스화 파라미터를 확정한다. **Q1~Q4가 아키타입·엔진을 결정**하므로 먼저 묻고, 나머지(Q5~Q11)는 인스턴스화 파라미터다. 각 문항은 아래 "질문 / 선택지 / 기본값 / 왜 묻는가" 네 칸으로 묻는다. 레퍼런스 구현(`problems/marketing/1.youth_policy`)은 난이도 2단계·9축 매칭이다.

## 진행 규칙 (먼저 읽어라)

- **필수 문항**: **Q1·Q2·Q6**. 이 셋이 비면 진행하지 않는다(AskUserQuestion으로 다시 채운다).
- **즉시 분기 규칙**: **Q2/Q4가 매칭이 아니면**, 나머지 문항을 묻기 전에 즉시 S1.5 **아키타입 라우팅**(`archetypes.md`)으로 넘어간다. 매칭이 아닌 형태(대사·집계·랭킹·퍼널)는 축↔컬럼 대신 산식↔입력열로 의미가 바뀌어 Q5/Q6이 무의미해지므로, 라우터가 "미지원 + 수동 설계 가이드"를 정직하게 반환한다.
- **Q4 아키타입 매칭 자동화**: Q4는 직접 묻되, 기본은 **라우터형 + 매칭 자동 매칭**이다 — 즉 사용자가 명시하지 않으면 Q2(직무×업무형태)에서 아키타입을 **자동 판정**해 매칭 여부를 가른다. 사용자가 원하면 Q4로 명시 override.
- 묻는 순서: Q1 → Q2 → (자동 아키타입 판정) → Q3 → Q4(확인/override) → 매칭 확정 시 Q5~Q11.

## 문항표

| # | 질문 | 선택지 | 기본값 | 왜 묻는가 |
|---|---|---|---|---|
| **Q1** (필수) | 테마 / 실제 도메인 | 자유서술 + 실제 출처 URL·포스터 유무 | (필수, 기본값 없음) | 회사색 제거 후에도 실데이터로 그라운딩하려면 실제 도메인이 필요. (예: youth_policy = 청년몽땅정보통) |
| **Q2** (필수) | 대상 직무 × 업무형태 | `_6` 카탈로그: GEN(G1~G12) / MKT(M1~M12, 분야 10종) | (필수, 기본값 없음) | 이 한 쌍이 **아키타입**을 결정한다(`archetypes.md` 매핑). 라우터의 엔진 선택 진입 키. |
| **Q3** | 결과물 형태 | ① 순수 분석 리스트(셀 비교) ② 분석 + 구조화 생성물 슬롯 ③ 생성물 포함 | **①** | 채점 결정성을 가른다. [생성]형 카피는 메인 채점에서 제외("이메일 문구는 안 만든다"). |
| **Q4** | 아키타입 | 매칭 / 디둑·정규화 / 대사 / 가중 랭킹 / 퍼널·코호트 (`_6` 매핑) | **매칭** (라우터형이되 Q2에서 자동 매칭, 필요 시 명시 override) | 엔진 선택. 매칭이 아니면 즉시 S1.5 라우팅으로 분기(`archetypes.md`). |
| **Q5** | 난이도 | 1(엑셀+안내시트만) / 2(멀티모달+다조건) / 3(다출처 가중·랭킹) | **2** | `_5`의 7노브로 같은 채점성을 유지한 채 조절. youth_policy = 2단계. |
| **Q6** (필수) | 판정 '축' ↔ 데이터 컬럼 | 축 목록 입력 → 각 축마다 회원/엔티티 컬럼 **1:1 강제**(5~9축) | (필수, 기본값 없음) | **교집합 불변식**의 입력. youth_policy = 9축(나이↔생년월일 …). 짝 없는 축은 거부한다. |
| **Q7** | 주입할 결함 (다중선택) | □경계값(±1) □표기불일치(주소류) □판별불가(추천안함) □빈칸=무관 □다출처조인 □멀티모달OCR | 경계값 + 표기불일치 + 판별불가 + 빈칸 + 멀티모달 | 변별 포인트. 결함이 결정성과 충돌하면 버린다("마감 2주 필터"는 날짜통제 모순으로 **제거**한 전례). |
| **Q8** | 실데이터 vs 통제값 경계 | 어느 축 = 실제 추출 / 어느 값 = 고정 통제 | 자격 = 실데이터, 시간축 = 통제/제거 | 통제 불가 요소(날짜)를 통제값으로 우회해 함정 결정성을 확보. |
| **Q9** | 고정 기준값 · 규모 | 기준일 · 시드 · 엔티티 수 | `ASSIGN_DATE`(과제부여일) / `seed` 고정 / **엔티티 500~1,000명 유동(기본 800)** | 재현성. 같은 입력 = 같은 정답. 규모는 채점 속도·변별 균형으로 800 기본, 필요 시 조절. |
| **Q10** | 단계 결합 vs 분리 | 결합(Part1 실패→Part2 전이) / 분리(Part2에 정답입력 별도 제공) | **분리형(decouple)** | 가혹함 조절. 기본은 분리 — Part2에 정답 정책표를 별도 입력으로 제공해 각 단계가 자기 역량으로만 채점된다. |
| **Q11** | 학생 수준 | 비개발자(브리프+안내시트) / 개발 가능 | **비개발자** | `problem.md` = 쉬운 업무 브리프, 정확한 판정 규칙은 엑셀 '안내' 시트로 이전. |

## 기본값 출처 일관성 (SKILL.md "기본값"과 동일)

| 항목 | 확정 기본값 |
|---|---|
| 아키타입(Q4) | 라우터형 — **매칭 자동 매칭**(Q2에서 판정), 매칭 계열만 자동 생성 |
| 단계 구조(Q10) | **분리형(decouple)** — Part2에 정답 정책표 별도 제공 |
| 데이터 규모(Q9) | **500~1,000명 유동, 기본 800** |
| 멀티모달(Q7 포스터) | **운영자 수동 배치** — 코드 생성 불가, 소싱 가이드만 제공(`multimodal-sourcing.md`) |
| 학생 수준(Q11) | 비개발자 |

- 비매칭 판정 → S1.5에서 `archetypes.md`로 "미지원 + 수동 가이드" 반환 후 종료.
