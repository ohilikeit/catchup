# data/briefs/ — 캠페인 브리프 소싱 가이드 (운영자 배치)

이 폴더에는 학생이 **대상 조건을 읽어낼 실제 캠페인 브리프(이미지·PDF)** 가 들어간다.
브리프는 코드가 만들지 않는다 — **운영자가 직접(수동) 배치**한다. 이 문서는 그 파일을
**무엇을·어디서·어떤 검색어로** 가져와 **어떻게 배치/검증**하는지 안내한다.
(공통 원칙·검증법 전체는 스킬의 `references/multimodal-sourcing.md` 참조.)

> 검증된 사례: `problems/marketing/1.youth_policy/data/policies/`. 그 과제의 `policies.csv`
> `poster_file` 9개 값이 실제 파일명과 1:1로 맞춰져 있다. 이 과제는 그 구조를 CRM 도메인으로
> 옮긴 것이다(`poster_file` → `brief_file`, `data/policies/` → `data/briefs/`).

---

## 0. 대원칙 — 브리프는 코드가 만들지 않는다 (환각 금지)

- ⭐ **브리프 이미지/PDF는 `build_dataset.py`가 생성하지 않는다.** 빌드는 이 폴더를 만들거나
  지우거나 건드리지 않는다. 운영자가 실제 출처에서 받아 `data/briefs/`에 직접 배치한다.
  코드가 그럴듯한 브리프를 지어내면 **대상 수치가 환각**돼 결정성이 깨진다 — 절대 금지.
- ⭐ **`brief_file` 컬럼 값 = `data/briefs/`의 실제 파일명과 글자 그대로 정확히 일치**해야
  한다(확장자·공백·괄호·한글·특수문자 포함). 불일치하면 학생이 그 브리프를 찾지 못한다.
- 책임 분리: **`campaigns.csv` = 채점 기준값(정답)** / **브리프 = 학생이 읽을 실제 입력**. 둘은
  같은 대상 조건을 담되, CSV는 코드가 쓰고 브리프는 사람이 배치한다.
- `brief_file`이 비어 있어도 데이터 생성·채점은 동작한다. 그러나 브리프는 **학생의 유일한
  입력 소스**이므로 발행 과제에는 **반드시** 실제 파일이 있어야 한다.

---

## 1. 현재 CSV가 요구하는 브리프 (캠페인 1건당)

각 행에서 **빈칸이 아닌 대상 조건 축이 그 브리프 한 장에서 모두 읽혀야** 한다. 현재 `campaigns.csv` 구성:

| campaign_id | brief_file | 한 장에 보여야 할 대상 조건 |
|---|---|---|
| `C01` | `C01_winback.png` | 휴면 90일 이상 · 만 25~54세 · 마케팅 수신동의 고객 (이메일) |
| `C02` | `C02_vip.png` | VIP 등급 · 누적구매 100만원 이상 · 수신동의 고객 감사 프로모션 (이메일) |
| `C03` | `C03_active.png` | 최근 14일 이내 구매(활성) · 일반 등급 리텐션 (앱푸시) |
| `C04` | `C04_apppush.png` | 앱푸시 선호 · 앱 설치 고객 한정 이벤트 (앱푸시) |
| `C05` | `C05_popup.png` | 서울 거주 · 만 20~39세 오프라인 팝업 초대 (SMS) |
| `C06` | `C06_gold.png` | 골드 등급 전용 · 수신동의 프로모션 (이메일) |
| `C07` | `C07_offline.png` | 오프라인 매장 방문 고객 전용 (**판별 불가** — 명단으로 확인 불가, `matchable=N`) |

> ⚠️ `C07`은 `matchable=N`(판별 불가) 캠페인이다. 브리프는 배치하되 CSV의 자격 칸은 **모두
> 빈칸**이며 정답 매칭은 0건이다. 학생이 "고객 명단으로 확인 불가 → 추천 0건"이라는 현업적
> 신중함을 판단하도록 하는 입력이다.

## 2. 소싱 절차 (캠페인 1건당)

1. **무엇이 브리프에 보여야 하는지 먼저 적는다** — 위 표의 "한 장에 보여야 할 대상 조건".
2. **1~2페이지 홍보·기획물을 우선 확보한다.** 우선순위: **① 1장짜리 캠페인 배너/포스터
   (JPG/PNG) → ② 카드뉴스 1~2컷 → ③ 이벤트 안내 페이지 캡처 1p**. ❌ 3페이지 이상 기획서·
   사업 안내 책자는 지양(추출 부담·OCR 난이도 폭발).
3. **대상 조건이 "한 장 안에" 다 보이는지 확인한다.** 흩어져 있으면 더 압축된 홍보물로 교체.
4. **`brief_file` 이름과 일치시켜 배치한다.** 파일을 `data/briefs/`에 넣고 파일명을
   `campaigns.csv`의 `brief_file` 값과 정확히 맞춘다(또는 CSV 값을 실제 파일명으로 통일).
5. **가독성(OCR 가능) 확인** — 대상 수치(나이·휴면 기간·금액·등급)가 또렷이 읽혀야 한다.

### 도메인 메모
- 이커머스 CRM 크리에이티브는 공공 포털보다 **브랜드 블로그·디자인 레퍼런스 사이트·이메일
  갤러리**(예: reallygoodemails 류)에서 더 잘 나온다. 출처가 명확하고 개인정보가 없는
  공개 크리에이티브를 우선한다.
- 실제 회사 로고/브랜드가 박힌 이미지는 가급적 피하고(특정 회사색 배제), **범용 리텐션
  캠페인** 느낌의 크리에이티브를 고른다. 직접 캡처/제작한 1p 브리프도 무방하다 — **브리프의
  숫자가 `campaigns.csv` 값과 일치**하기만 하면 된다(브리프가 대상 조건의 단일 출처).
- `C07`(오프라인 방문 전용)은 "매장 방문 고객 전용 / 오프라인 멤버십" 류 안내물을 쓰되,
  대상 수치는 비운 채 '방문 이력 기준'이라는 문구만 읽히면 된다.

## 4. 받아도 되는 형식 · 검증

- **PNG / JPG**(대상 수치가 또렷한 가독 이미지) 또는 **텍스트 레이어 있는 1~2p PDF**만 사용.
- ❌ 웹페이지 링크(HTML)·로그인 뷰어 전용·hwp는 1p 이미지/PDF로 캡처·변환 후 배치.

```bash
# (1) content-type (HTML 오류페이지 적발)
curl -sIL "<URL>" | grep -i content-type      # image/png|image/jpeg|application/pdf 여야 정상
# (2) 형식·크기
file   data/briefs/<brief_file>                # PNG/JPEG/PDF 인지
ls -lh data/briefs/<brief_file>                # 수십 KB 미만이면 깨졌을 가능성
# (3) PDF 페이지 수(3p 이상 지양)
pdfinfo data/briefs/<brief_file> | grep -i pages
```

마지막으로 **사람이 직접 열어** §1 표의 대상 조건이 한 화면에서 또렷이 읽히는지 눈으로 확인한다.

## 5. 함정 ↔ 결정성 분리 (중요)

- **경계값 함정은 고객 측(생성기)에서 만든다.** 만 나이 경계, 휴면일수 89/90/91, 누적구매액
  ±1원, 등급/채널/동의 경계 고객은 `build_dataset.py`가 `campaigns.csv` 기준으로 심는다.
  브리프는 그 기준값을 사람이 읽도록 보여줄 뿐 함정을 추가하지 않는다.
- **브리프에 없는 조건은 CSV에서 비운다**(빈칸=무관). 브리프 ↔ CSV의 비어있지-않은 조건 축은
  **일치**해야 한다.
- **멀티모달 OCR 자체가 '난이도'다.** 채점은 OCR 결과가 아니라 **CSV 기준값과 학생 셀을
  대조**(`grade.py`)한다 — 브리프가 좀 흐려도 정답은 흔들리지 않는다.
- **`matchable=N` 캠페인(C07)의 브리프**도 배치하되, CSV의 자격 칸은 모두 **빈칸**으로 둔다.

## 6. 발행 전 점검

- [ ] `brief_file`이 비어있지 않은 모든 행에 `data/briefs/`의 **실제 파일이 존재**한다.
- [ ] 파일명이 `brief_file` 값과 **글자 그대로 일치**한다(공백·확장자 포함).
- [ ] 각 파일이 **1~2페이지** 배너/카드뉴스/안내이고, 3p 이상 기획서가 아니다.
- [ ] 각 행의 **비어있지-않은 대상 조건이 그 브리프 한 장에서 모두 읽힌다**(사람 눈 확인).
- [ ] 브리프 ↔ CSV의 조건이 **일치**한다(브리프에 없는 조건은 CSV에서 비움).
- [ ] 모든 파일이 가독 가능하고 개인정보·특정 회사 브랜드가 없다.
