# 평가 방식 (evaluation)

> 제출물을 **정답키와 자동 대조**한다. 채점 스크립트는 [`grade.py`](grade.py), 정답키는 [`answer_key/`](answer_key/). 결과(문제 해결) 점수만 다룬다 — 과정(AI 협업)은 별도 루브릭.

채점 아키타입 = **분류(다클래스 macro-F1 + 혼동행렬)**. 두 축(문의유형 6클래스, 감성 3클래스)을 각각 macro-F1으로 채점한다.

## §1 제출물 스키마 — 컬럼 × 형식/허용값 × 채점유형

행 단위 = **VOC 1건**. 정답은 모두 생성된 `text`에 규칙북을 재적용한 값에서 나온다. 제출은 `classification_template.xlsx`의 **'분류' 시트**, 컬럼 순서 `item_id, 문의유형, 감성`.

| 컬럼 | 형식 / 허용값 | 채점유형 |
|---|---|---|
| `item_id` | `V001`… (키, 양식에 미리 채워짐) | — |
| `문의유형` | `환불취소`\|`배송문제`\|`제품불량`\|`사용법문의`\|`칭찬감사`\|`기타` (이 6개만) | macro-F1 (6클래스) |
| `감성` | `긍정`\|`부정`\|`중립` (이 3개만) | macro-F1 (3클래스) |

> `item_id`는 양식에 채워져 있다(채점 안 함, 정답 대조 키). 라벨집합 외 값·빈칸은 정규화 후 `(무효)` 센티넬로 떨어져 **오답 + 무결성 감점**. 정답에 없는 item_id를 추가하면 **유령ID**로 무결성 감점. 행 순서는 무관(item_id로 조인).

## §2 채점 로직 — grade.py 트리 + 정규화 규칙

```
grade.py
├─ norm_str/norm_type/norm_senti   # 공백 제거 + 동의어(ALIAS) 흡수, 라벨집합 외/빈칸 → (무효)
├─ load_sheet(path, "분류")        # openpyxl 로드 → 빈 행 스킵, item_id 조인
├─ grade_axis(gold, sub, ...)      # 한 축의 클래스별 TP/FP/FN → 정밀도·재현율·F1 → macro-F1 + 혼동행렬
├─ fmt_confusion(conf, labels)     # 혼동행렬 텍스트 출력(행=정답, 열=제출, 맨 끝 열=(무효))
├─ score(rt, rs, ghost_n)          # 유형 macro×45 + 감성 macro×45 + 무결성(10 - 위반×0.5)
└─ main()                          # 콘솔 표 + 혼동행렬 2개 + result.json
```

**다클래스 macro-F1**: 클래스별로 `정밀도 = TP/(TP+FP)`, `재현율 = TP/(TP+FN)`, `F1 = 2PR/(P+R)`를 구하고, **gold에 등장(support>0)하거나 제출된(pred>0) 클래스**에 대해 F1을 단순 평균. 다수 클래스로만 찍으면 소수 클래스 F1=0이 평균에 그대로 들어가 점수가 급락한다(다 찍기 처벌).

**정규화 규칙(채점 관용)**:
- `norm_str` — 모든 공백 제거. (`환불 취소` ≡ `환불취소`)
- `norm_type` — 동의어 흡수: `환불`·`취소`·`반품`·`환불/취소`·`환불·취소`→`환불취소`, `배송`·`배송지연`→`배송문제`, `불량`·`하자`·`고장`→`제품불량`, `사용법`·`사용방법`→`사용법문의`, `칭찬`·`감사`→`칭찬감사`, `그외`→`기타` 등. 6라벨 외 값은 `(무효)`.
- `norm_senti` — `긍정`/`positive`/`pos`/`+`/`긍`→긍정, `부정`/`negative`/`neg`/`-`/`부`→부정, `중립`/`neutral`/`중`→중립. 대소문자 무시. 3라벨 외 값·빈칸은 `(무효)`.

> 정답은 모든 클래스의 라벨이 유효하다(규칙북 도출). 제출만 `(무효)`가 발생할 수 있고, 이는 해당 축에서 오답(정답 클래스의 재현율을 깎음)으로 처리되며 무결성에서도 감점된다.

## §3 배점표 — 영역 × 배점 × 산정

| 영역 | 배점 | 산정 |
|---|--:|---|
| 문의유형 macro-F1 | 45 | macro-F1 × 45 |
| 감성 macro-F1 | 45 | macro-F1 × 45 |
| 무결성(라벨집합 외·빈칸·유령ID) | 10 | `max(0, 10 − 위반건수 × 0.5)` |

합격선(1단계 능력) = 명확한 다수 문장을 규칙대로 라벨링. 변별(2단계) = 충돌·약한신호·판별불가·소수 클래스까지 규칙대로 처리. 자기채점(정답키를 제출로 넣으면) **총점 100**.

### 흔한 실패 = 의도한 함정 적중

- **다수 클래스로 다 찍기** → 소수 클래스(칭찬감사·긍정) F1=0 → macro 평균 급락.
- **유형충돌을 우선순위 무시하고 분류** → 환불취소를 배송문제로 등 오분류(혼동행렬에 비대각 셀).
- **감성충돌을 긍정으로 분류** → 부정 재현율 하락(부정→긍정 혼동).
- **약한신호를 유형 따라 감성 추론** → 중립을 긍정/부정으로 오분류.
- **판별불가를 무리하게 추측** → 기타·중립이 다른 클래스로 새며 FP 발생.
- **라벨집합 외 값/빈칸** → `(무효)` 오답 + 무결성 감점.

## §4 정답키 생성·관리 — 단일 입력 원칙

- 정답키와 학생 데이터·제출양식은 **단일 입력 `items.csv`에서 같은 스크립트(`build_dataset.py`)로** 나온다 → 항상 정합.
- 바꾸려면 **`items.csv`만 수정** 후 재실행(생성물 `*.xlsx` 수기 편집 금지).
- 생성기 책임: 시나리오 → 자연어 text 합성 → **규칙북 재적용으로 정답 도출** → `cross_check`(규칙도출 == 의도라벨) fail-loud 자기검증. `ASSIGN_DATE`·`seed`는 상수 고정(`datetime.now()` 미사용, 날짜는 채점에 미사용).

## §5 실행 커맨드

```bash
# 데이터·정답 생성 (items.csv 하나만 읽음)
python3 eval/answer_key/build_dataset.py
#   → data/voc_데이터.xlsx, data/classification_template.xlsx, eval/answer_key/classification_answer.xlsx

# 학생 제출물 채점
python3 eval/grade.py \
  --submission data/classification_template.xlsx \
  --answer-dir eval/answer_key
#   → 콘솔 표 + 혼동행렬(유형·감성) + result.json

# 자기채점(정답키 자기검증, 100점 기대)
python3 eval/grade.py \
  --submission eval/answer_key/classification_answer.xlsx \
  --answer-dir eval/answer_key
```
