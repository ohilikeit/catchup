# 키워드 목록 합치고 우선순위 매기기 — 흩어진 키워드 표를 하나로

> **유형** ②취합/통합 · **보조** ③집계/분석 · **직무** 마케팅(MKT) · **원본** _6 MKT-L1-X1 · **난이도** 1
> **입력 → 출력**: 키워드 툴에서 내려받은 엑셀 여러 개 → 중복 뺀 키워드 표 + 우선순위 점수
> **판별**: "여러 파일을 행 보존해 합치고 중복만 정리했는가"

## 어떤 일인가요

당신은 마케팅팀에 막 들어온 신입입니다. 검색 광고나 콘텐츠 기획을 하려면 "사람들이 어떤 단어로 검색하는지"를 모아둔 **키워드 목록**이 필요해요. 그런데 이 목록은 여러 도구에서 따로따로 나옵니다 — 어떤 건 검색 도구에서, 어떤 건 광고 관리 화면에서 뽑아 와요.

이번 주 당신의 일은 — 여기저기서 내려받은 키워드 엑셀 여러 개를 **하나의 깔끔한 표로 합치는 것**입니다. 같은 키워드가 파일마다 겹쳐 들어 있고, 표기도 조금씩 달라요(띄어쓰기·대소문자 등). 이걸 사람이 손으로 정리하면 하루가 갑니다. 그래서 앞으로 파일만 넣으면 자동으로 합쳐지고 정리되게 만드는 게 목표예요.

## 받는 자료

- **키워드 엑셀 여러 개** — 각 파일에 키워드, 월 검색량(볼륨), 경쟁 난이도 같은 숫자가 들어 있어요. 파일마다 칸 이름이나 표기가 조금씩 다를 수 있습니다.

## 할 일

- 여러 파일을 **하나의 표로 모읍니다.** 한 파일도 빠뜨리지 말고 전부 합치세요.
- 같은 키워드가 여러 번 나오면 **하나로 합칩니다.** 띄어쓰기나 대소문자만 다른 건 같은 키워드로 봐 주세요.
- 합친 다음, 검색량이 많고 경쟁이 덜한 키워드가 위로 오도록 **우선순위 점수**를 붙입니다.

## 잘된 결과물

키워드마다 한 줄씩, 중복 없이 정리된 표. 옆에 검색량·난이도와 우선순위 점수가 같이 있어서, 위에서부터 "먼저 노려볼 키워드"를 한눈에 알 수 있어요.

## 이런 건 조심

- **합치는 게 먼저, 줄이는 건 그다음.** 합치다가 키워드를 실수로 빠뜨리면 안 됩니다. 일단 다 모은 뒤 중복만 정리하세요.
- 같은 키워드인지 헷갈리는 표기(예: 띄어쓰기 차이)는 **묶을지 말지 기준을 정해두고 일관되게** 적용하세요. 어떤 줄은 묶고 어떤 줄은 안 묶으면 결과가 들쭉날쭉해집니다.
- 우선순위 점수는 검색량·난이도가 비어 있는 키워드라면 무리해서 매기지 말고 그대로 두세요.
