# 페이지 메타정보 점검 — 규칙에 어긋난 페이지 찾기

> **유형** ⑥검증/검수 · **직무** 마케팅(MKT) · **원본** _6 MKT-L1-X4 · **난이도** 1
> **입력 → 출력**: 페이지 목록 엑셀(주소·제목·설명) + 규칙 안내 → 길이 초과·중복·누락 위반 항목표
> **판별**: "정해진 규칙에 어긋난 행만 위반으로 판정했는가"

## 어떤 일인가요

당신은 마케팅팀 신입입니다. 회사 웹사이트의 페이지마다 검색 결과에 보이는 **제목(타이틀)**과 **설명(디스크립션)**이 붙어 있어요. 이게 너무 길거나, 여러 페이지가 똑같은 제목을 쓰거나, 아예 비어 있으면 검색에 불리합니다.

이번 주 당신의 일은 — 페이지 목록을 받아서, **정해진 규칙에 어긋난 페이지만 골라내는 것**입니다. 규칙은 안내에 정리돼 있어요(예: 제목 길이 한도, 중복 금지, 빈칸 금지). 당신이 좋고 나쁨을 새로 판단하는 게 아니라, **이미 정해진 규칙에 맞는지 아닌지만** 보면 됩니다.

## 받는 자료

- **페이지 목록 엑셀** — 한 줄에 페이지 하나. 주소·제목·설명이 들어 있어요.
- **규칙 안내** — 무엇을 위반으로 볼지 적힌 기준(길이 한도, 중복 금지, 누락 금지 등).

## 할 일

- 페이지 하나하나를 규칙에 비춰 봅니다.
- **길이가 한도를 넘었는지, 다른 페이지와 겹치는지, 빈칸인지**를 확인합니다.
- 규칙에 어긋난 페이지만 모아, **어떤 규칙을 어겼는지**와 함께 표로 정리합니다.

## 잘된 결과물

위반한 페이지만 한 줄씩 모은 표. 각 줄에 "어떤 규칙을 어겼는지"(길이 초과/중복/누락)가 적혀 있어, 그대로 고치러 갈 수 있어요.

## 이런 건 조심

- **정답은 규칙입니다.** 당신 취향으로 "이 제목 별로네"라고 잡으면 안 돼요. 규칙에 어긋난 것만 위반입니다.
- 규칙을 지킨 멀쩡한 페이지를 위반으로 잘못 넣지 마세요. 위반 목록이 부풀면 고치는 사람이 헷갈립니다.
- 한 페이지가 여러 규칙을 동시에 어겼다면, 어긴 규칙을 빠짐없이 다 적어주세요.
