# 평가 방식 (evaluation)

> 제출물 2개를 **정답키와 자동 대조**한다. 채점 스크립트는 [`grade.py`](grade.py), 정답키는
> [`answer_key/`](answer_key/). 결과(문제 해결) 점수만 다룬다 — 과정(AI 협업)은 별도 루브릭.

## §1 제출물 스키마

### Part 1 — 계약대장 (`contract_ledger_template.xlsx`, '계약대장' 시트)

행 단위 = 계약 1건. 키 = `계약번호`(미리 채워짐, 채점 안 함). 정답은 모두 `contracts.csv` 값에서 나온다.

| 컬럼 | 형식 / 허용값 | 채점유형 |
|---|---|---|
| `계약번호` | `CT-…` (키) | — |
| `계약명` | 계약서에 적힌 명칭 | Exact (공백 무시) |
| `거래상대방` | 계약서에 적힌 상대방 | Exact (공백 무시) |
| `계약유형` | `임대`\|`용역`\|`구독`\|`유지보수`\|`라이선스` | Exact |
| `시작일` | `YYYY-MM-DD` | Exact (날짜 정규화) |
| `종료일` | `YYYY-MM-DD` (미표기 계약은 시작일+기간으로 계산) | Exact (날짜 정규화) |
| `계약금액` | 정수(원). 미기재면 **빈칸** | Exact (숫자 정규화, 빈칸≠0) |
| `자동갱신` | `Y`\|`N` | Exact (Y/N 정규화) |
| `갱신통지일` | 정수(일). 자동갱신=N이면 **빈칸** | Exact (숫자 정규화, 빈칸≠0) |

### Part 2 — 만료·갱신 대상표 (`expiry_targets_template.xlsx`, '대상목록' 시트)

행 단위 = `(계약번호, 대상유형)` 1조합. **튜플 집합**(행 순서 무관·중복 1개 간주). `사유`는 참고용
(채점 안 함). 예시행(`예시…`)은 무시.

| 컬럼 | 형식 / 허용값 | 채점유형 |
|---|---|---|
| `계약번호` | `CT-…` | Set |
| `대상유형` | `만료경과`\|`만료임박`\|`자동연장주의` | Set |

> 어디에도 해당 안 되는 계약은 적지 않는다(빈 제출이 정답일 수도 있음). 한 계약이 복수 유형이면
> 행도 여러 개. 미리 채워진 칸·예시행은 채점하지 않는다.

## §2 채점 로직 — grade.py 트리 + 정규화 규칙

```
grade.py
├─ load_sheet(path, sheet)   # openpyxl(data_only) 로드 → 헤더 매핑, 빈 행 제거
├─ grade_part1(sub, ans)     # 셀 Exact: 계약번호로 조인, LEDGER_FIELDS 8칸 필드별 일치 집계
├─ grade_part2(sub, ans, k)  # 집합 비교: {(계약번호,대상유형)} → precision/recall/F1, FP·FN 분리
│                            #            + 무결성(유령 계약번호 / 허용 외 대상유형)
└─ score() / report()        # 차원 분리 배점(JSON + 콘솔 표)
```

정규화 규칙(채점 관용 — 과민 채점 방지):
- `norm_str` — 모든 공백 제거 후 비교(계약명·상대방 표기 관용).
- `norm_int` — `₩`·`원`·콤마·한글 병기·`.0` 제거 후 숫자만. **빈칸 보존**(빈칸=미기재 ≠ 0).
- `norm_date` — `2026년 8월 7일`/`2026.08.07`/`2026/08/07`/ISO/엑셀 datetime → `YYYY-MM-DD`.
- `norm_yn` — `Y/예/O/유/있음` → `Y`, `N/아니오/X/무/없음` → `N`.
- `norm_target` — `만료경과`(≡기간만료), `만료임박`(≡갱신대상·만료예정), `자동연장주의`(≡자동갱신
  위험·통지필요) 동치 흡수.
- 빈 집합(정답=제출=∅) → F1 = 1.0.

## §3 배점표

| 영역 | 배점 | 산정 |
|---|--:|---|
| Part 1 계약대장 추출 정확도 | 50 | (정확 셀 / 전체 채점 셀 240) × 50 |
| Part 2 만료·갱신 F1 | 40 | F1 × 40 |
| Part 2 무결성(유령 계약번호·허용 외 대상유형 0건) | 10 | 위반 1건당 0.5점 감점 |

합격선(1단계 능력): 양식 일부에서 기한·금액을 옮기고 명백한 만료를 추림. 변별(2단계): 표기 변형을
정규화하고, 자동연장주의를 만료임박과 분리하며, 종료일 미표기·금액 미기재를 정확히 처리.

### 흔한 실패 = 의도한 함정 적중

- 날짜를 문자열로 비교 → 표기 변형 계약에서 시작일·종료일 셀 오답.
- "대충 두 달" 처리 → 남은날 60/61, 통지마감 30/31 경계에서 만료임박·자동연장주의 오분류.
- 자동갱신 조항 무시 → 자동연장주의 FN(놓침), 또는 통지 여유 계약을 올려 FP.
- 종료일 미표기 계약을 빈칸/오계산 → 종료일 셀 오답 + 그 계약의 만료 판정 연쇄 오류.
- 금액 미기재를 0/"별도"로 채움 → 계약금액 셀 오답(빈칸≠0).

## §4 정답키 생성·관리 — 단일 입력 원칙

정답키와 제공 데이터(계약서 PDF·양식)는 **단일 입력 `contracts.csv`에서 같은 스크립트
`build_dataset.py`로** 나온다 → 항상 정합. 바꾸려면 **CSV만 수정** 후 재실행(생성물 수기 편집 금지).
`ASSIGN_DATE=2026-06-28` 상수 고정(`datetime.now()` 미사용) — 만료 판정의 기준일이자 종료일 합성
기준. 정답은 플래그를 직접 읽지 않고 합성 계약에 갱신 규칙을 **재적용**해 도출한다(`derive_targets`),
플래그 의도(`expected_from_flags`)와 `cross_check`로 대조해 발행 전 자기검증한다.
