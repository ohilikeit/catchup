# 평가 방식 (evaluation)

> 제출물 1개를 **정답키와 자동 대조**한다. 채점 스크립트는 [`grade.py`](grade.py), 정답키는 [`answer_key/`](answer_key/).
> 결과(문제 해결) 점수만 다룬다. 과정(AI 협업) 점수는 채팅 로그 기반 별도 루브릭.

---

## 1. 제출물 스키마 (정답이 결정되는 형식)

### 견적 비교표 — `견적비교표_제출용.xlsx` · 시트 `견적비교표`
행 단위 = **품목 1건** (`품목코드` 1개, 한 줄). 정답은 모두 생성된 4소스를 통합 규칙으로 재구성한 값에서 나온다. 컬럼 순서: `품목코드,품목명,규격,가람상사_단가,나래유통_단가,다온오피스_단가,라온문구_단가,최저가,최저가거래처`.

| 컬럼 | 형식 / 허용값 | 채점유형 |
|---|---|---|
| `품목코드` | `OF-1001`… (키) — 결과 표에 **유일**해야 함 | Set (키) |
| `품목명` | 문자열. 거래처 우선순위(가나다) 1위 표기. 앞뒤 공백 제거 | Exact (`norm_str`) |
| `규격` | 문자열. 거래처 우선순위 1위 표기 | Exact (`norm_str`) |
| `가람상사_단가` | 정수(원). 콤마 제거. **미견적이면 빈칸** | Exact (`norm_int`) |
| `나래유통_단가` | 정수(원). **미견적이면 빈칸** | Exact (`norm_int`) |
| `다온오피스_단가` | 정수(원). `원`·콤마 제거. **미견적이면 빈칸** | Exact (`norm_int`) |
| `라온문구_단가` | 정수(원). **미견적이면 빈칸** | Exact (`norm_int`) |
| `최저가` | 정수(원). 견적 단가 최솟값. **비교불가면 빈칸** | Exact (`norm_int`) |
| `최저가거래처` | 거래처명(`가람상사`/`나래유통`/`다온오피스`/`라온문구`) 또는 `비교불가` | Exact (`norm_str`) |

> 채점은 **품목코드 키로 조인 + 8개 표준 칸 셀 Exact** 와 **`{품목코드}` 행집합 Set** 을 결합한다. **행 순서 무관**, 같은 품목코드의 중복 행은 과잉 병합 실패(중복 미접기)로 본다(첫 행만 셀 비교에 사용, 나머지는 무결성·정밀도에서 처벌). **빈칸과 0은 구분**한다(`norm_int`: 빈칸=미견적/비교불가, `0`=단가 0원). 거래처별 단가가 동점이면 우선순위(가나다)가 빠른 거래처가 `최저가거래처` 정답이다.

## 2. 채점 로직 (`grade.py` 구성요소)

```
grade.py
├─ load_sheet(path, sheet)            # openpyxl 로드(data_only) → 헤더 정규화, 빈 행 스킵
├─ norm_str / norm_int                # 칸별 정규화(아래 규칙)
├─ grade_part1(sub, ans)             # 비교표: Set(품목코드) + Exact(정규화 셀)
│   • 품목코드 키로 정답·제출 조인. 제출은 키별 행 목록(중복 탐지)
│   • 행집합: tp=A∩S, fp=S−A(유령/과잉병합), fn=A−S(누락)
│       precision = tp / 제출 원본행수(중복·유령이 분모에 그대로 남아 정밀도 하락)
│       recall    = tp / 정답 키수,  F1 = 2PR/(P+R)
│   • 셀 Exact: 정답 키마다 (중복이면 첫 행) 8칸 정규화 후 일치 집계 → 필드별·전체 셀 정확도
│   • 무결성: 유령 품목코드(미존재 키) + 중복 미접기(같은 품목코드 2행+) 집계
└─ score(p1) / report()              # 영역별 점수 합산 + JSON·콘솔 표
```

### 정규화 규칙(채점 관용)
- `norm_str`(품목명·규격·최저가거래처): 모든 공백 제거 후 비교 — 앞뒤 trim 함정 흡수, 내부 공백 표기차도 관용. `비교불가`·거래처명은 공백 없어 그대로 비교.
- `norm_int`(거래처별 단가·최저가): 콤마·`원`·`₩`·공백·`.0` 제거 후 정수 비교. **빈칸과 0은 구분**(빈칸=미견적/비교불가, 0=단가 0원).
- 빈 데이터(정답·제출 모두 0행) F1=1로 처리. 양식의 '예시' 행(`예시OF-0001`)은 정답 키에 없으므로 유령으로 잡힌다 → 학생은 예시 행을 지우고 제출해야 한다.

## 3. 배점 (결과 점수 100점)

| 영역 | 배점 | 산정 |
|---|--:|---|
| 견적비교표 — 셀 Exact | 60 | 셀정확도(정확 셀 / 전체 채점 셀) × 60. 전체 셀 = 정답 품목수 × 8칸 (현재 48×8 = 384) |
| 견적비교표 — 행집합 Set-F1 | 30 | `{품목코드}` 집합의 F1 × 30 |
| 무결성 | 10 | `max(0, 10 − (유령행수 + 중복미접기수) × 0.5)` |

> **합격선(1단계 능력)**: 4소스를 일관 파싱해 품목코드로 묶고 거래처별 단가를 펼쳐 비교표를 만들고 컬럼·단가를 정규화. **변별**: 품목명 변형을 우선순위로 통일하고, 빈칸 보존·동점 우선순위·단위 불일치(비교불가)·동명 규격 분리까지 통과해 셀 정확도와 행집합 F1을 동시에 끌어올림.

### 흔한 실패 = 의도한 함정 적중
- 품목명으로 묶음(품목코드 무시) → 별칭/공백 품목이 갈리거나 동명 품목이 잘못 합쳐짐 → 행집합 **재현율 하락(FN) + 셀 오답**.
- 컬럼명 매핑 실패·단가 콤마/`원` 못 떼냄 → `*_단가`·`최저가` **셀 오답** 대량.
- 견적 안 한 칸을 0/임의값으로 채움 → 빈칸≠0이라 **단가 셀 오답**.
- 최저가 동점에서 우선순위 무시 → `최저가거래처` **셀 오답**.
- 단위 다른 품목을 무리해서 비교(최저가 단정) → `최저가`·`최저가거래처` **셀 오답**.
- 한 거래처 전용 품목을 빠뜨림 → 행집합 **재현율 하락(FN)**. / 예시 행을 남김 → **유령(FP) + 무결성 감점**.

## 4. 정답키 생성·관리

- 정답키(`answer_key/견적비교표_정답.xlsx`)와 제공 데이터(`../데이터/`의 4소스·제출양식)는 **단일 입력 [`answer_key/quotes.csv`](answer_key/quotes.csv)** 에서 같은 스크립트로 나온다 → 데이터·정답이 항상 정합.
- 정답 도출은 `quotes.csv`를 직접 베끼지 않는다 — **생성된 4소스를 다시 파싱하고 통합 규칙(정규화·키 통합·우선순위·최저가)을 재적용**해 비교표를 재구성한다(독립 검증). canonical 의도와의 일치는 `cross_check`가 fail-loud로 자기검증한다.
- 품목을 바꾸려면 **`quotes.csv`만 수정**하고 생성 스크립트를 다시 돌려 **데이터와 정답키를 동시 갱신**한다(생성물 수기 편집 금지). CSV 작성법은 [`answer_key/INPUT_GUIDE.md`](answer_key/INPUT_GUIDE.md).
- 생성기: [`answer_key/build_dataset.py`](answer_key/build_dataset.py) — `quotes.csv` 읽기 → 4소스(양식 제각각) 렌더 + 제출양식 + 정답키를 일괄 산출. `random.seed(20260628)` 상수 고정(`datetime.now()` 미사용), 전역 누적상태 없음 → 언제 재생성해도 동일.
