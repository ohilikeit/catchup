# INPUT_GUIDE — quotes.csv 채우는 법 (출제자용)

이 과제의 **모든 데이터·정답은 단일 입력 파일 `quotes.csv` 하나에서 생성**된다.
`quotes.csv`(canonical 1행=1품목)를 실제 견적으로 채우고 `build_dataset.py`를 재실행하면,
4개 거래처 소스(양식 제각각)·제출 양식·정답키가 **항상 정합하게 함께 갱신**된다. 수기로
엑셀을 고치지 말 것.

> ⚠️ **현재 들어 있는 `quotes.csv`는 사무용품 견적을 본뜬 샘플 겸 템플릿이다.**
> 컬럼 형식과 함정 구성을 그대로 보여주기 위한 예시이므로, 출제 시 **실제 견적
> 데이터로 행을 교체**해서 쓰면 된다. 헤더(컬럼명)는 절대 바꾸지 말 것.
> canonical 1행은 "비교표에 들어갈 최종 1품목"이고, 각 거래처 단가 칸이 그 품목을
> 어느 거래처가 견적했는지를 정한다.

---

## 1. 컬럼 의미 / 형식 (헤더 순서 고정)

| 컬럼 | 의미 | 형식 / 예시 |
|------|------|------------|
| `item_id` | 품목 고유키(품목코드) | `OF-1001`… (중복 금지 — canonical 품목은 유일) |
| `품목명` | 정식 품목명 | 자유 문자열 (비울 수 없음). 비교표 정답 품목명 = 이 값 |
| `품목명_별칭` | 별칭(줄여/달리 부른 이름) | 자유 문자열. `표기변형=품목명별칭`일 때만 사용(그 외엔 비워도 됨) |
| `규격` | 규격/사양 | 자유 문자열 (비울 수 없음) |
| `단위` | 가격 단위 | `박스`·`개`·`통`·`갑` 등 (비울 수 없음) |
| `가람상사_단가` | 가람상사 견적가(원) | 정수. **비우면 가람상사 미견적**(그 칸 빈칸) |
| `나래유통_단가` | 나래유통 견적가(원) | 정수. 비우면 미견적 |
| `다온오피스_단가` | 다온오피스 견적가(원) | 정수. 비우면 미견적 |
| `라온문구_단가` | 라온문구 견적가(원) | 정수. 비우면 미견적 |
| `표기변형` | 품목명 표기 함정 | `none` \| `품목명공백` \| `품목명별칭` (§3) |
| `비교가능` | 단위 비교 가능 여부 | `Y`(기본) \| `N`(단위 불일치 → 비교불가) (§4) |

`item_id`·`품목명`·`규격`·`단위`는 비울 수 없다. 각 품목은 **최소 한 거래처 단가**가 있어야 한다(present≥1). 빈 행은 무시된다.

> ⭐ **거래처 단가 칸이 present(견적한 거래처 집합)를 만든다.** 비지 않은 단가 칸들이 그 품목을 견적한
> 거래처다. 비교표는 **품목코드**를 키로 1행, 거래처별 단가를 옆으로 펼친다. 견적 안 한 거래처 칸은
> 비교표에서 **빈칸**(0 아님). 거래처 추가는 아래 ⭐박스 2 참조.

## 2. 거래처 우선순위 — 품목명·동점 처리

- **우선순위(가나다)**: `가람상사 > 나래유통 > 다온오피스 > 라온문구`. `build_dataset.py`의 `VENDORS` 리스트 순서 = 우선순위.
- **품목명·규격 표기**: 거래처마다 품목명 표기가 달라도, 그 품목을 견적한 거래처 중 **우선순위 1위** 거래처의 표기를 비교표에 쓴다(정답 품목명 = canonical `품목명`. §3 별칭 함정에서도 1위 거래처가 정식명을 보이므로 일치).
- **최저가 동점**: 견적 단가 최솟값이 두 거래처에서 같으면 **우선순위가 빠른 거래처**를 `최저가거래처`로 한다.

## 3. 표기변형 — 품목명 함정

- `표기변형=none`: 모든 거래처가 정식 `품목명`을 그대로 적는다.
- `표기변형=품목명공백`: 모든 거래처 파일에서 품목명 앞뒤에 공백이 주입된다(→ 학생이 trim해야 함). 정답 품목명은 trim된 `품목명`.
- `표기변형=품목명별칭`: 그 품목을 견적한 거래처 중 **우선순위 1위만 정식 `품목명`**, 나머지는 `품목명_별칭`을 적는다(→ 이름이 달라도 품목코드로 같은 물건임을 알아내야 함). **`품목명_별칭`이 채워져 있어야 하고, 거래처 2곳 이상**이어야 한다(비우선 거래처가 있어야 별칭이 보인다).
- ⚠️ **모순 입력은 fail-loud 차단**: `품목명별칭`인데 `품목명_별칭`이 비었거나 거래처가 1곳이면 생성기가 즉시 중단한다.

## 4. 비교가능 — 단위 불일치(비교불가) 함정

- `비교가능=Y`: 그 품목을 견적한 모든 거래처가 **같은 단위**로 적는다 → `최저가`·`최저가거래처` 정상 산출.
- `비교가능=N`: 거래처들이 **서로 다른 단위**로 적는다(생성기가 우선순위 1위는 `단위`, 나머지는 `alt_unit`으로 다른 단위 렌더) → 가격 직접 비교 불가. 정답은 `최저가` **빈칸**, `최저가거래처`=`비교불가`. **거래처 2곳 이상**이어야 한다(단위가 갈리려면).
- ⚠️ `비교가능=N`인데 거래처가 1곳이면 fail-loud로 중단한다.

## 5. 거래처 소스에는 별도 파일 배치가 필요 없다

이 과제는 멀티모달(포스터/이미지) 입력이 없다. 학생용 입력 4소스(`가람상사_견적서.xlsx`·`나래유통_견적서.csv`·
`다온오피스_견적서.xlsx`·`라온문구_견적서.xlsx`)는 모두 `build_dataset.py`가 `quotes.csv`에서 **자동 생성**한다 —
운영자가 따로 넣을 파일이 없다.

## 6. 재생성 → 채점 절차

```bash
# 1) quotes.csv 를 실제 견적으로 채운다 (헤더 유지, item_id 중복 금지, 품목당 단가 최소 1칸)
# 2) 데이터·정답 동시 생성
python3 eval/answer_key/build_dataset.py
#    → 데이터/가람상사_견적서.xlsx, 데이터/나래유통_견적서.csv,
#       데이터/다온오피스_견적서.xlsx, 데이터/라온문구_견적서.xlsx
#    → 데이터/견적비교표_제출용.xlsx (제출 양식: '안내'+'견적비교표' 시트)
#    → eval/answer_key/견적비교표_정답.xlsx (정답키)
# 3) 학생 제출물 채점 (Set(품목코드) + Exact(정규화 셀))
python3 eval/grade.py \
  --part1 데이터/견적비교표_제출용.xlsx \
  --answer-dir eval/answer_key
```

**⭐박스 1 — `비교가능=N`의 의미(비교불가 품목)**: 한 품목을 거래처들이 서로 다른 단위로 견적하면(예: 박스당 vs 개당) 가격을 곧바로 비교할 수 없다 → 무리해서 최저가를 단정하지 않고 `최저가`를 비우고 `최저가거래처`에 `비교불가`라고 적는 것이 유일 정답이다. 이는 "확인 불가하면 무리하지 않는" 현업의 신중함을 측정한다(youth_policy의 `matchable=N`과 같은 철학). 생성기는 `비교가능=N`이면 거래처 단위를 실제로 다르게 렌더해 학생이 데이터에서 불일치를 발견하게 한다. `비교가능` 컬럼 자체는 비교표에 노출되지 않는 **운영 전용** 정보다.

**⭐박스 2 — 거래처(컬럼) ↔ 소스 교집합(불변식)**: 비교표의 각 거래처 단가 칸은 그 거래처 소스에 대응 원본 컬럼이 **반드시** 있어야 채워진다. 대응: 가람상사_단가↔`단가`·나래유통_단가↔`price`·다온오피스_단가↔`공급가`·라온문구_단가↔`판매가`. **거래처를 추가/변경하려면 `quotes.csv`(단가 컬럼 헤더)·`build_dataset.py`(`VENDORS`·`VENDOR_FILES`·렌더)·`grade.py`(`VENDORS`·`STD_FIELDS`)에 짝을 함께 추가**(한 곳만 늘리면 통합 불가). 우선순위는 `VENDORS` 리스트 순서로 결정된다.
