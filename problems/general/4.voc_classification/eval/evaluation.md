# 평가 방식 (evaluation)

> 제출물 2개를 **정답키와 자동 대조**한다. 채점 스크립트는 [`grade.py`](grade.py), 정답키는 [`answer_key/`](answer_key/). 결과(문제 해결) 점수만 다룬다 — 과정(AI 협업)은 별도 루브릭.

채점 아키타입 = **분류(다클래스 macro-F1 + 혼동행렬) + 교차집계(셀 Exact)**. 세 축(문의유형 6클래스, 감성
3클래스, 위험 2클래스)을 각각 macro-F1으로, 채널별 교차집계는 셀 단위 Exact로 채점한다.

## §1 제출물 스키마 — 컬럼 × 형식/허용값 × 채점유형

### Part 1 — 3축 분류 (`1_분류표_제출용.xlsx`, '분류' 시트)

행 단위 = **VOC 1건**. 정답은 모두 생성된 `text`에 규칙북을 재적용한 값에서 나온다. 컬럼 순서
`item_id, 채널, 문의유형, 감성, 위험`.

| 컬럼 | 형식 / 허용값 | 채점유형 |
|---|---|---|
| `item_id` | `V001`… (키, 양식에 미리 채워짐) | — |
| `채널` | 앱리뷰\|고객센터메일\|전화상담\|문의게시판\|SNS (미리 채워짐) | — |
| `문의유형` | `환불취소`\|`배송지연`\|`제품하자`\|`사용문의`\|`칭찬감사`\|`기타` (이 6개만) | macro-F1 (6클래스) |
| `감성` | `긍정`\|`부정`\|`중립` (이 3개만) | macro-F1 (3클래스) |
| `위험` | `위험`\|`일반` (이 2개만) | macro-F1 (2클래스) |

### Part 2 — 채널별 교차집계 (`2_채널별집계_제출용.xlsx`, '교차집계' 시트)

행 단위 = **채널 1개**(5행). 정답은 정답 분류표(`2_분류결과_참고용.xlsx`)에서 채널×유형·채널별 위험건수를
센 값이다. 컬럼 = `채널` + 유형 6열(`환불취소`…`기타`) + `위험건수` = 7열 → 5채널 × 7열 = **35칸**.

> `item_id`·`채널`은 양식에 채워져 있다(채점 안 함, 정답 대조 키). 라벨집합 외 값·빈칸은 정규화 후
> `(무효)` 센티넬로 떨어져 **오답 + 무결성 감점**. 정답에 없는 item_id를 추가하면 **유령ID**로 무결성
> 감점. 교차집계 셀이 정수가 아니거나 빈칸이면 **무효셀**로 오답 + 무결성 감점. 행 순서는 무관(키로 조인).

## §2 채점 로직 — grade.py 트리 + 정규화 규칙

```
grade.py
├─ norm_str/norm_type/norm_senti/norm_risk  # 공백 제거 + 동의어(ALIAS) 흡수, 라벨집합 외/빈칸 → (무효)
├─ norm_int                                 # 교차집계 셀: 콤마/공백 제거, 정수 아니면 None(무효)
├─ load_sheet(path, "분류")                 # Part1 로드 → 빈 행 스킵, item_id 조인
├─ load_crosstab(path)                      # Part2 로드 → 채널(A열) × 칼럼 딕셔너리
├─ grade_axis(gold, sub, ...)              # 한 축의 클래스별 TP/FP/FN → macro-F1 + 혼동행렬
├─ grade_crosstab(ans_tab, sub_tab)        # 채널×칼럼 35셀 Exact 대조 → correct/total + 무효
├─ fmt_confusion(conf, labels)             # 혼동행렬 텍스트 출력(행=정답, 열=제출, 끝 열=(무효))
├─ score(rt, rs, rr, ct, ghost_n)         # 유형25 + 감성20 + 위험20 + 교차집계30 + 무결성(5)
└─ main()                                  # 콘솔 표 + 혼동행렬 3개 + 교차집계 정확도 + result.json
```

**다클래스 macro-F1**: 클래스별로 `정밀도 = TP/(TP+FP)`, `재현율 = TP/(TP+FN)`, `F1 = 2PR/(P+R)`를
구하고, **gold에 등장(support>0)하거나 제출된(pred>0) 클래스**에 대해 F1을 단순 평균. 다수 클래스로만
찍으면 소수 클래스 F1=0이 평균에 그대로 들어가 점수가 급락한다(다 찍기 처벌).

**교차집계 Exact**: 정답키 35셀을 채널(A열)·칼럼명으로 조인해 `norm_int` 값 일치 여부를 센다.
`correct/total`이 점수 비율. 무효셀(정수 아님/빈칸)은 오답 + 무결성 감점.

**정규화 규칙(채점 관용)**:
- `norm_str` — 모든 공백 제거. (`환불 취소` ≡ `환불취소`)
- `norm_type` — `환불`·`취소`·`반품`·`환급`→`환불취소`, `배송`·`택배`·`배송문제`→`배송지연`,
  `불량`·`하자`·`고장`·`파손`→`제품하자`, `사용법`·`사용방법`→`사용문의`, `칭찬`·`감사`→`칭찬감사`,
  `그외`→`기타` 등. 6라벨 외 값은 `(무효)`.
- `norm_senti` — `긍정`/`positive`/`pos`/`+`/`긍`→긍정, `부정`/`negative`/`neg`/`-`/`부`→부정,
  `중립`/`neutral`/`중`→중립. 대소문자 무시. 3라벨 외 값·빈칸은 `(무효)`.
- `norm_risk` — `위험`/`Y`/`긴급`/`높음`/`주의`→위험, `일반`/`N`/`정상`/`낮음`→일반. 2라벨 외 값·빈칸은 `(무효)`.
- `norm_int` — 콤마·공백 제거 후 정수면 int, 아니면 무효(빈칸 포함).

> 정답은 모든 클래스의 라벨이 유효하다(규칙북 도출). 제출만 `(무효)`가 발생할 수 있고, 이는 해당 축에서
> 오답(정답 클래스의 재현율을 깎음)으로 처리되며 무결성에서도 감점된다.

## §3 배점표 — 영역 × 배점 × 산정

| 영역 | 배점 | 산정 |
|---|--:|---|
| 문의유형 macro-F1 | 25 | macro-F1 × 25 |
| 감성 macro-F1 | 20 | macro-F1 × 20 |
| 위험 macro-F1 | 20 | macro-F1 × 20 |
| 채널별 교차집계 Exact | 30 | (정확 셀 / 35) × 30 |
| 무결성(라벨집합 외·빈칸·유령ID·교차집계 무효셀) | 5 | `max(0, 5 − 위반건수 × 0.5)` |

합격선(1단계 능력) = 명확한 다수 문장을 규칙대로 라벨링 + 기본 집계. 변별(2단계) = 충돌·약한신호·판별불가·
위험 축독립·소수 클래스까지 규칙대로 처리하고 채널별 집계를 정확히. 자기채점(정답키를 제출로 넣으면) **총점 100**.

### 흔한 실패 = 의도한 함정 적중

- **다수 클래스로 다 찍기** → 소수 클래스(칭찬감사·기타·긍정) F1=0 → macro 평균 급락.
- **유형충돌을 우선순위 무시하고 분류** → 환불취소를 배송지연으로 등 오분류(혼동행렬 비대각 셀).
- **감성충돌을 긍정으로 분류** → 부정 재현율 하락(부정→긍정 혼동).
- **약한신호를 유형 따라 감성 추론** → 중립을 긍정/부정으로 오분류.
- **위험을 감성으로 추론** → 화났지만 일반인 건을 위험으로(오버), 차분한 법적위협을 일반으로(언더) 오분류.
- **판별불가를 무리하게 추측** → 기타·중립·일반이 다른 클래스로 새며 FP 발생.
- **교차집계를 자기 분류 결과로 셈** → 참고용 정답표 대신 틀린 분류로 세면 셀 불일치(분리형 의도 위반).
- **라벨집합 외 값/빈칸/비정수 셀** → `(무효)` 오답 + 무결성 감점.

## §4 정답키 생성·관리 — 단일 입력 원칙

- 정답키와 학생 데이터·제출양식은 **단일 입력 `items.csv`에서 같은 스크립트(`build_dataset.py`)로** 나온다 → 항상 정합.
- 바꾸려면 **`items.csv`만 수정** 후 재실행(생성물 `*.xlsx`/PDF 수기 편집 금지).
- 생성기 책임: 시나리오 → 자연어 text 합성 → **규칙북 재적용으로 정답 도출** → `cross_check`(규칙도출 ==
  의도라벨) fail-loud 자기검증 → 정답 분류표에서 교차집계 카운트. `ASSIGN_DATE`·`seed`는 상수 고정
  (`datetime.now()` 미사용, 날짜는 채점에 미사용).

## §5 실행 커맨드

```bash
# 데이터·정답 생성 (items.csv 하나만 읽음)
python3 eval/answer_key/build_dataset.py
#   → 데이터/1_VOC_원문.xlsx, 1_분류기준_위험규칙.pdf, 1_분류표_제출용.xlsx,
#     2_분류결과_참고용.xlsx, 2_채널별집계_제출용.xlsx
#   → eval/answer_key/1_분류표_정답.xlsx, 2_채널별집계_정답.xlsx

# 학생 제출물 채점
python3 eval/grade.py \
  --part1 데이터/1_분류표_제출용.xlsx \
  --part2 데이터/2_채널별집계_제출용.xlsx \
  --answer-dir eval/answer_key
#   → 콘솔 표 + 혼동행렬(3축) + 교차집계 정확도 + result.json

# 자기채점(정답키 자기검증, 100점 기대)
python3 eval/grade.py \
  --part1 eval/answer_key/1_분류표_정답.xlsx \
  --part2 eval/answer_key/2_채널별집계_정답.xlsx \
  --answer-dir eval/answer_key
```
