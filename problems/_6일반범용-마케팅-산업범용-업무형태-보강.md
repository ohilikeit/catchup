# 일반-범용(GEN)·마케팅(MKT) — 산업 범용 업무 형태 보강

> **이 문서의 위치**: [_5직무-바이브코딩-과제설계.md](_5직무-바이브코딩-과제설계.md)의 **보조(확장) 문서**.
> 5직무 설계 중 **내가 담당한 2개 직무 — 일반-범용(GEN)·마케팅(MKT)** 만 떼어내, 우리 회사(입시·대학 IT 서비스) 색이 묻은 소재를 **산업 무관한 보편 업무 형태**로 일반화하고, 기존 75개 매트릭스에 바로 끼울 수 있는 **확장 사례 뱅크**를 같은 표 형식으로 추가한다.
> **불변**: 난이도 사다리(1~3단계)·6대 DNA·채점 5유형·결정성 원칙은 [_5](_5직무-바이브코딩-과제설계.md) 그대로 계승. 이 문서는 **소재(업무 형태)의 폭만** 넓힌다.
> **근거**: 두 입력 파일(`2025 부서별 AX 과제_v.2.xlsx`·`AI 이용현황 설문조사_결과보고_0617.xlsx`)에서 *업무 수행 형태*만 추출 + 산업 전반 웹 리서치(출처는 §7).

## 0. 왜 이 보강이 필요한가 — 회사 편향 진단

기존 [_5](_5직무-바이브코딩-과제설계.md)의 GEN·MKT 소재는 전부 `AX 과제` 파일에서 왔고, 그 파일은 **우리 회사 내부 18개 부서**만 조사한 것이다. 그래서 소재가 입시·대학 IT 서비스 맥락에 묶여 있다.

| 직무 | 기존 소재의 회사 색(편향) | 추출해야 할 **업무 형태**(범용) |
|---|---|---|
| GEN | 콜통계 리포트, 카카오 친구통계, 모집요강 명부, 원서 테스트 | "다채널 통계 자동 취합", "비정형 입력→규칙 분류", "두 대장 대사" |
| MKT | 대학 배너 소재 제작, 유튜브 레퍼런스 서치, 모집 시즌 카드뉴스 | "다채널 지표 통합→캠페인 랭킹", "외부 비정형 소스→정형 시트 수집" |

> **핵심 원리(사용자 지시 그대로)**: "합격 예측 리포트 경향성 분석"은 우리 회사만 하지만, 거기서 가져갈 것은 **"여러 데이터 소스를 종합해 경향성을 뽑는다"는 작업 형태**다. 소재는 산업 무관하게 바꾸되, **형태와 채점 구조는 보존**한다. 이 문서의 모든 확장 사례가 그 변환을 따른다.

세 갈래 리서치가 한 점으로 수렴한 결론도 같다 — **직무·산업이 달라도 신입 반복업무의 뼈대는 `다출처 비정형 입력 → 규칙/KPI 적용 → 정형 표 출력`** 하나다. 이는 [_5 §2](_5직무-바이브코딩-과제설계.md)의 6대 DNA와 동일하므로, 난이도 사다리는 건드리지 않는다.

**대상층 재확인(설문)**: 자동화 워크플로우 직접 제작 6.4%, n8n/스크립트 연동 1.3%, 역할·형식·제약까지 구조화한 프롬프트 8.5%. → **새 소재를 넓혀도 풀이 난이도 상한은 기존 1~3단계에 그대로 묶는다.** 보강의 목표는 "더 어렵게"가 아니라 "더 다양하게"다.

## 1. GEN(일반-범용) — 산업 범용 사무직 업무 형태 카탈로그 (12종)

> 모든 형태를 회사 특화가 아닌 **"흩어진 입력 → 규칙/매칭/검증 → 정형 xlsx"** 로 환원했다. 산업(제조·유통·금융·공공·병원·교육·건설·F&B·스타트업) 무관 보편 형태만 골랐다.

| # | 업무 형태(추상) | 흔한 산업/직무 | 입력 형태 | 출력 형태 | 매핑 단계 |
|---|---|---|---|---|---|
| G1 | **두 대장 대사(2-way/3-way matching)** — 다른 출처의 동일 거래를 키로 매칭→불일치 플래그 | 회계 AP(발주·납품·세금계산서), 재무(은행거래 vs 장부), 물류(WMS vs ERP) | PO·GRN·인보이스 xlsx/PDF 다수 | 매칭표 + 불일치(예외) 목록 | 2~3 |
| G2 | **비정형 입력 → 규칙 분류(코딩)** — 텍스트/이미지를 룰·키워드로 카테고리 판정 | 회계(영수증→계정과목), CS(문의→유형), 총무(지출 분류) | 영수증 이미지(OCR)·카드내역·거래명세 | 분류 코드가 채워진 정형 표 | 1~3 |
| G3 | **다출처 종합 → 경향 집계 리포트** — 양식 제각각 N개를 union→피벗·추세 | 영업지원(지점별 매출), HR/설문(부서별 결과), CS(주간 통계) | 부서·지점별 xlsx N개(스키마 상이) | 통합 요약 + 전월/전년 대비 추세표 | 1~3 |
| G4 | **템플릿 문서 일괄 생성(mail-merge)** — 데이터 N행 × 템플릿 → 개별 문서 N개 | 인사(증명서·근로계약·임명장), 총무(품의·통지서), 영업지원(견적서) | 신청 데이터 xlsx + 템플릿 | 채워진 문서(xlsx/docx) 일괄 + 발급대장 | 1~2 |
| G5 | **명부·대장 입력 정합성 검증** — 형식·중복·필수값 validate | 행정 전반(직원·자산·고객 DB), 공공(민원대장) | 신규 데이터(폼·이미지·엑셀) | 통과/오류 분리된 대장 + 오류 사유 | 1~2 |
| G6 | **근태·시간 데이터 → 급여/정산 산출** — 타임스탬프에 연장·공제 규칙 적용 | HR 보조(근태→급여기초), 파견(타임시트 정산) | 출퇴근 로그·타임시트 CSV | 근무·연장·공제 계산된 산출표 | 1~2 |
| G7 | **다중 견적 비교 → 최저가/조건 선정** — 벤더별 견적 정규화→side-by-side | 구매/조달, 총무(비품 구매) | 벤더별 견적서 PDF/엑셀(양식 상이) | 항목별 비교표 + 추천(최저가·조건) | 2 |
| G8 | **재고·자산 실사 대사(cycle count)** — 장부 vs 실물 정기 대조 | 물류/재고, 총무(자산실사), 유통(점포) | 실사 카운트 xlsx + 시스템 재고 export | 차이(shrinkage) 표 + 조정 제안 | 2 |
| G9 | **문의/티켓 분류·라우팅·통계화** — 유형 규칙 라벨링→우선순위·집계 | CS, IT 헬프데스크, 공공 민원 | 문의 텍스트(엑셀/메일 export) | 분류·우선순위 티켓표 + 채널×유형 통계 | 1~2 |
| G10 | **OCR 증빙 취합 + 정책 검증** — 영수증 추출→한도·항목 룰 검증 | 회계·재무(경비정산), 출장·법인카드 | 영수증 이미지/스캔 PDF + 규정 PDF | 추출·검증된 경비표 + 위반 플래그 | 2~3 |
| G11 | **계약·문서 등록 → 기한/만료 추적** — 기한·갱신·금액 모니터링 | 총무(계약대장), 공공조달, 법무보조 | 계약 PDF + 등록 엑셀 | 만료·갱신 대상표(기한순) + 알림 슬롯 | 1~2 |
| G12 | **다채널 주문/유입 데이터 표준화** — 형식 제각각 → 공통 스키마 정규화 | 영업지원·주문처리, 구매(발주 생성) | 주문서 메일/PDF/엑셀(채널별 상이) | 표준화된 주문/발주 정형 표 | 1~2 |

**산업 전반에서 가장 보편적인 사무 자동화 TOP 10**(리서치 종합): ① 데이터 입력·전사 ② 송장 3-way 매칭 ③ 경비 OCR+정책검증 ④ 은행/거래 대사 ⑤ 계정과목 분류 ⑥ 근태→급여 ⑦ CS 티켓 분류·통계 ⑧ 다출처 리포트 취합 ⑨ 구매 견적 비교·발주 ⑩ 온보딩 인사행정.

> **기존 GEN 5사례와의 관계**: 기존은 G2·G3·G9에 집중(설문집계·티켓·민원). **새로 비는 칸 = G4(대량 문서 생성)·G7(견적 비교)·G8(재고 실사)·G11(계약 만료)·G12(주문 표준화)**. 이들이 IT서비스 색이 가장 옅고 산업 보편성이 가장 높아, 확장 뱅크의 1순위(§3).

## 2. MKT(마케팅) — 분야 분화 + 업무 형태 카탈로그

마케팅은 단일 직무가 아니라 **퍼포먼스 / 콘텐츠 / 소셜·커뮤니티 / SEO·SEM / CRM·라이프사이클 / 브랜드·PR / 그로스·프로덕트 / 이커머스·리테일 / 마켓리서치 / 이벤트·제휴**로 갈라진다. 분야는 달라도 신입 반복업무는 **"다채널 데이터 통합 → KPI/규칙 계산 → 정형 표·랭킹"** 으로 수렴한다(마케터는 주당 9시간+를 수작업 데이터 이동에 쓴다 — Parseur).

### 2.2 마케팅 신입 자동화 대상 **[분석]형** TOP 12 (채점 친화 순)

> 모두 결과가 수치/표/분류로 떨어져 "정답 xlsx ↔ 제출 xlsx" 셀 비교 자동 채점이 가능. **[생성]형(카피 등)은 메인 채점에서 빼고 과정 점수/가점 슬롯으로** ([_5 §6.2](_5직무-바이브코딩-과제설계.md)).

| # | 작업 형태(추상) | 입력 | 출력 | 채점유형 |
|---|---|---|---|---|
| M1 | 다채널 지표 통합 → KPI 계산 | 매체별 export 3~5개(헤더 제각각) | 통합 KPI 표(CPC·CPA·ROAS) | Computed |
| M2 | 캠페인 랭킹 + 이상치 플래그 | 캠페인×일자 성과표 | 랭킹 + 임계 규칙 라벨 | Rank/Exact |
| M3 | 예산 대비 소진/편차 체크 | 비용 시트 + 예산표 | 소진율 표 + 초과 알림 | Computed |
| M4 | A/B·실험 결과 비교 → 승자 판정 | 변형 A/B 지표 | 비교표 + 유의·승자 | Computed/Set |
| M5 | 다출처 리스트 정규화·중복제거(리드·키워드) | 중복 포함 다출처 리스트 | 디둑·정제표 + 우선순위 점수 | Exact/Computed |
| M6 | 퍼널 단계 전환·이탈 계산 | 이벤트 로그 | 퍼널표 + 최대 이탈 단계 | Computed |
| M7 | 코호트 리텐션 매트릭스 | 유저×주차 활동 | 코호트 삼각 매트릭스 | Computed |
| M8 | 세그먼트 분류(규칙 기반) | 고객 속성·행동 | 세그먼트 라벨 표 | Exact |

| M12 | 쿠폰/어트리뷰션 기여 집계 | 쿠폰 로그 + 주문 데이터 | 기여표 + ROI | Computed |

> **기존 MKT 5사례와의 관계**: 기존은 M1·M2·M4·M6·M9(통합대시보드·랭킹·A/B·퍼널·벤치마크·멘션)을 이미 커버. **새로 비는 칸 = M5(키워드·리드 디둑/의도분류)·M7(코호트 리텐션)·M8(규칙 세그먼트)·M12(쿠폰·어트리뷰션)** + 이커머스/이벤트·제휴 소재. 이들이 확장 뱅크 1순위(§3).

## 4. 채점 가능성 유지 — 새 소재에도 똑같이 적용

새 소재라도 [_5 §6](_5직무-바이브코딩-과제설계.md)의 결정성 제약은 1급이다. 산업 범용 소재에서 특히 주의할 변환:

- **(A) 기준 제공** — 견적 평가 가중치·쿠폰 기여 규칙·세그먼트 임계·커미션 요율은 **학생이 정하지 않고 PDF로 준다**. (`평가기준.pdf`·`기여규칙.pdf`·`세그먼트규칙.pdf`·`커미션정책.pdf`)
- **(B) 구조화 슬롯** — "벤치마크 리포트를 써라"가 아니라 "스코어카드의 이 칸들(점수·순위·갭)을 채워라".
- **(C) 근거 결속** — 멘션 분류·감성 같은 [생성/주관] 요소는 **닫힌 라벨 집합 + 라벨 일치율(정밀도/재현율)** 로만 채점. 카피·보도자료는 결과 채점에서 제외.
- **(D) 폐쇄화** — 견적·쿠폰·리드 입력을 설계할 때 각 항목이 한 정답에만 매핑되게(경계 모호 항목 배제). 모호하면 `비우기`·`제약 없음`.

**[분석] vs [생성] 분리 원칙(마케팅 필수)**: §2의 모든 [분석]형은 셀 비교로 자동 채점. **[생성]형(카피·상세설명·메타·보도자료)은 "추가 자동화 슬롯"으로 분리**해 형식/근거 제약만 검사(예: 1위 콘텐츠 대상·실제 수치 포함·해시태그 정확히 3개·제목 ≤20자), 문장 품질 자체는 과정 점수.

## 5. 입력 다양성·난이도 레버 (회사 색 없이 다양화하는 법)

같은 채점 구조를 유지하면서 소재만 다양하게 하려면 아래 레버를 조합한다(전부 [_5 §3](_5직무-바이브코딩-과제설계.md)의 7노브 하위 구체화).

| 레버 | 다양화 방법 | 적용 예 |
|---|---|---|
| **입력 출처 다양화** | 채널별 엑셀(헤더 불일치)·플랫폼 CSV export·설문 export·이벤트 로그·**스크린샷/PDF(OCR)**·비정형 텍스트 덤프 | 산업·회사를 바꿔도 형태 유지 |
| **헤더/스키마 불일치** | 같은 의미 컬럼을 파일마다 다른 이름·단위·날짜형식으로 | 정규화 역량 측정 |
| **OCR/표 추출** | 영수증·단가표·경쟁사 캡처를 이미지로 | 멀티모달 가산(2~3단계) |
| **다단계 조인** | 쿠폰×주문, 리드×전환, PO×GRN×인보이스 | 조인 정확도 |
| **임계·예외 규칙 수** | 허용오차·한도·우선순위·미등재 예외 | 규칙 적용 정밀도 |
| **중복·결측 처리** | 중복 주문·미매칭·결측 행을 의도적으로 심기 | 데이터 위생 |

## 6. 한 줄 요약

> 내가 맡은 **GEN·MKT 두 직무**의 소재가 우리 회사(입시 IT) 색에 묶이지 않도록, 두 입력 파일에서 **업무 *형태*만** 뽑아 산업 무관 카탈로그(GEN 12종·MKT 분야별 + [분석]형 TOP12)로 일반화하고, 기존 75개에 끼울 **산업 범용 확장 사례 24개**(`-X` 접미)를 같은 표·같은 채점 규격으로 추가했다. **난이도·DNA·채점 5유형·결정성은 [_5](_5직무-바이브코딩-과제설계.md) 그대로**, 바뀐 것은 *소재의 산업 폭*뿐이다 — 형태는 보존하고 회사 색만 벗긴다.
