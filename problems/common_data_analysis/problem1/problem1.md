# 문제1: 한국교육개발원 입찰공고 RSS 수집

Anchor: `ainc2026`

한국교육개발원 입찰공고 RSS를 수집하여 신규 입찰공고 목록을 확인하고, 각 공고 제목을 바탕으로 “**(주)진학테크**”(구체적인 회사 정보는 아래에 제공)와 관련 있을 가능성이 높은 공고를 1차 선별하는 프로그램을 작성합니다.

이 문제의 핵심은 입찰 가능 여부를 정확히 판정하는 것이 아니라, RSS 데이터를 수집하고 LLM API를 적절히 활용하여 **공고를 구조화된 형태로 분류하는 것**입니다.

## 데이터

- 입찰공고 RSS URL: 
https://www.kedi.re.kr/khome/main/announce/rssAnnounceData.do?board_sq_no=2

## (주)진학테크 

**(주)진학테크**는 교육기관과 공공기관을 대상으로 웹사이트 및 정보시스템 구축/운영, 시스템 유지보수, 교육 콘텐츠 및 프로그램 개발을 수행하는 중소 IT/에듀테크 기업이다.

주요 역량은 다음과 같다.

- 공공기관 홈페이지 구축 및 운영
- 교육 데이터 서비스 유지관리
- 정보시스템 유지보수
- 온라인 교육 프로그램 기획 및 콘텐츠 개발
- 교육 관련 콘텐츠 제작 및 운영

다음 유형의 사업은 수행하지 않는다.

- 물품 납품
- 인쇄 및 출판 대행
- 금융기관 선정
- 건강검진
- 식당, 카페, 매점 위탁운영

## 요구사항

1. 한국교육개발원 입찰공고 RSS에서 최소 15개 이상의 공고를 수집합니다.
2. 각 공고에서 **공고명, 게시 일자, 공고 링크**를 추출합니다.
3. LLM API를 사용하여 각 공고가 **(주)진학테크**와 관련 있을 가능성이 높은지 판단합니다.
4. 판단 결과는 `y` 또는 `n`으로 표시합니다.
5. 판단 사유를 한두 문장으로 생성합니다.
6. 최종 결과를 엑셀 형식으로 저장합니다. (`problem1` 폴더 내 `result.xlsx` 파일 참고)

## LLM API

- `gemini-3.1-flash-lite` 모델을 사용합니다.
- API Key는 코드에 직접 작성하지 않고 환경변수 또는 별도 설정 파일을 사용합니다.


## 필수 출력 컬럼

결과에는 아래 5개 컬럼이 반드시 포함되어야 합니다.

| 컬럼명 | 설명 |
| --- | --- |
| 공고명 | RSS에서 수집한 입찰공고 제목 |
| 게시 일자 | RSS의 `pubDate` 또는 `published` 값 |
| 공고 링크 | 상세 페이지 URL |
| 입찰 가능성 판단 | `y` 또는 `n` |
| 판단 사유 | LLM이 생성한 간단한 판단 근거 |

## 제출물

- `result.xlsx` 파일
