# 평가 방식 (evaluation)

> 제출물 1개를 **정답키와 자동 대조**한다. 채점 스크립트는 [`grade.py`](grade.py), 정답키는 [`answer_key/`](answer_key/).
> 결과(문제 해결) 점수만 다룬다. 과정(AI 협업) 점수는 채팅 로그 기반 별도 루브릭.

---

## 1. 제출물 스키마 (정답이 결정되는 형식)

### 참고 — 정책 정리(자격요건 추출)
학생은 `데이터/포스터/`의 포스터를 직접 읽어 각 정책의 자격요건(거주·연령·취업·기업규모·월소득·연소득·무주택·학력·혼인)을 스스로 정리한 뒤 매칭에 활용한다. 이 중간 정리표는 **채점 대상이 아니며 별도 제출도 요구하지 않는다** — 최종 채점은 아래 타게팅 리스트 하나만 본다. (운영자 내부 정답키는 `eval/answer_key/1_정책정리표_정답.xlsx`에 여전히 생성되지만 학생에게 노출되지 않는다.)

### 제출 — `제출물/최종제출.xlsx` · 시트 `타게팅`
행 단위 = **(회원 × 추천정책) 1조합**. 자격 조건(나이·거주·취업·기업규모·월소득·연소득·무주택·학력·혼인)을 모두 통과한 조합만 기록(신청 날짜는 보지 않음). 어떤 정책에도 안 맞는 회원은 적지 않는다. **`matchable=N` 정책은 어떤 회원도 통과시키지 않으므로 추천 0건이 정답**이다.

| 컬럼 | 형식 | 채점유형 |
|---|---|---|
| `회원ID` | `회원명단.xlsx`의 식별자 (`M0001`…) | Set |
| `추천정책ID` | `policies.csv`의 `policy_id`(`YP01`…) 중 **`matchable != N` 정책만**(날짜 무관) | Set |

> **정책ID 매핑 제공**: `추천정책ID`↔포스터 파일명 대응표는 `최종제출.xlsx`의 **`정책목록` 시트**로 학생에게 제공된다(학생이 ID를 발명할 여지 차단). 정의된 ID 외의 값은 참조 오류다.
>
> 채점은 **(회원ID, 추천정책ID) 튜플의 집합**으로 한다. **행 순서 무관**, 중복 행은 1개로 간주. 자격 판정은 9축(나이·거주·취업·기업규모·월소득·연소득·무주택·학력·혼인)으로만 한다. 단, **닫힌 세 유형**(① 본인이 아닌 가족(부모·배우자)의 소득·재산이 금액 기준으로 명시 ② 특정 대출을 받은 사람만 대상 ③ 자녀 필요)이 포스터 신청자격에 명시된 정책(`matchable=N`: YP04·YP06·YP09)은 아무에게도 추천하지 않는다. '(가구) 기준 중위소득 ○○% 이하' 소득 기준은 세 유형에 해당하지 않는다(월소득(중위소득%) 축으로 판정). 포스터에 명시 안 된 자격은 제약 없음으로 보고, 세 유형 외의 나머지 포스터 문구(신청 기간·전입 시기·절차·서류·수급자 여부·타 사업 참여 이력·기존 지원 한도·주택 거래금액·세금 조건 등)는 판정에 쓰지 않는다.

## 2. 채점 로직 (`grade.py` 구성요소)

```
grade.py
├─ load_xlsx(path, sheet)             # openpyxl 로드 → 정규화(공백 strip, 날짜 ISO, 숫자 캐스팅)
├─ grade_final(sub, ans)             # 타게팅: 집합 비교
│   • {(회원ID, 정책ID)} 집합화
│   • precision / recall / F1
│   • 오발송(정답 아닌데 보냄=FP)·누락(보내야 하는데 빠짐=FN) 분리 집계
├─ checks()                          # 무결성 검사 (경고 2종 분리)
│   • 미정의 정책ID(policies.csv에 없는 ID) 사용 = **참조 오류** 경고 (별도 출력)
│   • 'matchable=N' 정책 추천이 섞였는지 = **판별 불가 정책 추천** 경고 (별도 출력)
│   • '정답 0건 정책 추천' 경고 — matchable=Y이지만 정답 매칭이 0건인 정책을 추천한 경우
│   • '정책ID 체계 불일치' 배너 — 제출에 쓰인 정책ID가 정의된 ID와 한 종도 겹치지 않는 경우
│   • 회원ID 참조 무결성(존재하지 않는 ID 사용 탐지)
└─ report()                          # 부분점수 차원 분리 출력(JSON + 콘솔 표)
```

> result.json의 `추천불가정책추천` 키는 하위호환용으로, **미정의 정책ID 사용 ∪ 판별 불가(matchable=N) 정책 추천의 합집합**이다.

### 정규화 규칙(채점 관용)
- 빈 집합(정답·제출 모두 매칭 0건)의 F1=1로 처리. 템플릿의 '예시' 회원ID 행은 무시한다.
- 문자열(회원ID·정책ID): 앞뒤 공백·중복 공백 제거 후 비교.

## 3. 배점 (결과 점수 100점 기준 예시)

| 영역 | 배점 | 산정 |
|---|--:|---|
| 타게팅 F1 | 90 | F1 × 90 |
| 무결성(`matchable=N` 추천 0건) | 10 | **10 − 3 × (추천에 포함된 판별 불가 정책 종수), 하한 0** |

> 무결성은 **판별 불가 정책(`matchable=N`)을 추천 목록에 넣었는지**만 본다 — 감점 단위는 FP 행 수가 아니라 **정책 종수**(예: YP04·YP06 두 종 추천 → 10−6=4점). **FP 건수당 감점(구 −0.5/건)은 폐지** — 개별 오발송·누락은 이미 F1(90점)에 반영되므로 이중 감점하지 않는다. 미정의(존재하지 않는) 정책ID 사용은 무결성 감점이 아니라 **참조 오류 경고**로 별도 보고된다(해당 행은 정답 집합에 없으므로 F1에서 자연히 FP로 잡힘).

> **합격선(1단계 능력)**: 회원 명단·정책 자격을 일관 처리해 매칭 파이프라인을 완성. **변별(2단계)**: 경계값·주소 정규화를 모두 통과해 타게팅 F1을 끌어올림.

### 흔한 실패 = 의도한 함정 적중
- 만 나이를 출생연도 뺄셈으로 계산 → 생일 경계 회원 **오분류**.
- 주소를 문자열 그대로 비교 → `서울 노원구`를 자치구 매칭 실패 → **FN 급증**(누락).
- 지역 범위 오인 → 자치구·타시도 한정 정책을 '서울 전체'로 넘겨짚어 **FP/FN**, 또는 포스터에 없는 자격(무주택·소득)을 임의로 채워 매칭이 **틀어짐**.
- 판별 불가 정책(`matchable=N`: YP04·YP06·YP09)을 본인 자격이 맞아 보인다는 이유로 추천 → **FP**(오발송). 확인 불가 게이트(부모소득·학자금대출·자녀)를 임의 숫자로 채우거나, 회원 명단으로 확인 불가한 자격을 임의로 단정해 매칭을 틀어지게 만드는 경우도 흔하다.

## 4. 정답키 생성·관리

- 정답키(`answer_key/1_정책정리표_정답.xlsx`, `answer_key/2_추천리스트_정답.xlsx`)와 제공 데이터(`../데이터/`, `../제출물/`)는 **단일 입력 [`answer_key/policies.csv`](answer_key/policies.csv)** 에서 같은 스크립트로 나온다 → 정책·회원DB·정답이 항상 정합. (포스터 파일은 운영자가 `데이터/포스터/`에 직접 넣는다 — 코드 생성 아님)
- `answer_key/1_정책정리표_정답.xlsx`는 **운영자 전용 참고 자료**로만 생성된다(학생에게 노출되지 않고, 채점에도 쓰이지 않는다).
- 정책을 바꾸려면 **`policies.csv`만 수정**하고 생성 스크립트를 다시 돌려 **데이터와 정답키를 동시 갱신**한다(생성물 수기 편집 금지). CSV 작성법은 [`answer_key/INPUT_GUIDE.md`](answer_key/INPUT_GUIDE.md).
- 생성기: [`answer_key/build_dataset.py`](answer_key/build_dataset.py) — `policies.csv` 읽기 → 회원 합성(경계 회원 자동 삽입) + 제출양식(`제출물/최종제출.xlsx`) + 정답키 + 매칭 정답을 일괄 산출. 매칭 대상 = `matchable != N` 인 모든 정책(날짜 무관). 기준일 `ASSIGN_DATE = 2026-06-28` 상수 고정(`datetime.now()` 미사용) — **만 나이 계산에만** 쓰고 날짜 필터에는 쓰지 않는다.

## 5. 채점 실행

```bash
# 학생 제출물 채점
python eval/grade.py --submission 제출물/최종제출.xlsx --answer-dir eval/answer_key
# → 콘솔 표 + result.json (영역별 점수·FP/FN 목록)
```
