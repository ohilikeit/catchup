# 시험 환경 안내

이 환경은 **인터넷이 연결되어 있지 않습니다.** 도구를 새로 설치하려 하지 말고
아래에 미리 설치된 것을 그대로 사용하세요.

## 파일 읽는 방법

- **엑셀(.xlsx)** — `python3` + `openpyxl` (설치됨). 제출 파일은 새로 만들지 말고
  기존 파일을 열어 채운 뒤 같은 이름으로 저장합니다.
- **PDF** — `pdfplumber`(설치됨)로 텍스트를 추출합니다. **추출 결과가 비어 있으면
  스캔본(이미지형) PDF**이므로, 그 파일은 Read 도구로 직접 열어 눈으로 읽습니다.
- **이미지(png/jpg)·스캔본 PDF** — 코드로 변환하려 하지 말고 **Read 도구로 직접
  열어** 읽습니다. 이미지 속 글자를 읽을 수 있습니다.

## 작업 원칙

- 원본 자료(포스터·PDF·이미지)는 **파일당 한 번만 읽고**, 추출 결과를 중간 파일
  (CSV 등)로 저장해 이후 작업에서 재사용합니다. 같은 파일을 반복해 다시 열지 않습니다.
- 무엇을 추출하고 어떤 규칙으로 판단할지는 이 문서가 아니라 **과제의 문제.md와
  제출 파일의 안내 시트**를 따릅니다.
